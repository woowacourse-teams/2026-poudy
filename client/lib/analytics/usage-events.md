# 새 기능 이용 이벤트

커뮤니티는 공개 피드의 내용을 보는 이용도 포함한다. `routine_feed_item_viewed`는 카드가
절반 이상 0.5초 보이거나 실제로 선택된 경우 한 번 전송한다. 화면 밖 카드·빈 목록·요청 실패는
콘텐츠 열람으로 세지 않는다. 빠른 선택도 노출에 포함하며 같은 노출의 선택으로 중복 전송하지 않는다.

`routine_comment_submitted.is_routine_author`는 서버 응답의 `byRoutineAuthor`를 그대로 사용한다.
본인 댓글은 커뮤니티 반응에서 제외하고 내 루틴 이용에 포함한다. 작성자 정보가 없는 과거 이벤트를
다른 사람의 댓글이라고 추정하지 않는다. 닉네임·댓글 본문·프로필 주소는 전송하지 않는다.

공개 상세는 내 루틴 조회가 실패한 뒤 공개 조회로 전환하는 기존 경로에서 기록한다.
로그인한 본인의 상세는 `view_type=own`이므로 커뮤니티 상세 열람·반응의 분모에서 제외된다.
