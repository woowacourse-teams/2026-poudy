# 새 기능 분석

저장 전환을 성과 지표로 쓰지 않는다. 루틴 생성·구성·가져오기, 유사템 결과에서의 제품 탐색,
유튜버 콘텐츠에서의 제품 탐색·재생 요청, 마크 필터의 적용과 미리보기를 측정한다.

기존 `analytics_schema_version=4` 계약을 유지한다. 새 기능의 이동은 `feature_flow_id`로,
실제로 선택한 제품은 제품 ID와 구성품 ID로 연결한다. 표준 링크 주소는 그대로 두며 같은
탭의 이동 문맥만 세션 저장소에 보관한다. 기능 흐름은 1시간, 제품 유입 문맥은 30분 후 만료된다.
사용자가 다른 출처에서 같은 제품을 선택하면 이전 문맥을 교체한다.

화면·결과 이벤트는 성공한 데이터를 표시한 뒤 기록하고, 재렌더링으로 중복 전송하지 않는다.
실패를 결과 0건으로 처리하지 않는다. 생성·가져오기·편집 완료는 API 성공 뒤 기록한다.
루틴 이름·메모·댓글·닉네임·프로필 사진 주소는 이벤트 속성에 넣지 않는다.

루틴은 `routine_create_started` → `routine_created` → 제품이 생긴 `routine_products_updated`로
빈 루틴 생성과 실제 구성을 나눈다. 공개 상세의 `routine_import_started` → `routine_imported`는
원본 `source_routine_id`와 새 `routine_id`를 함께 보낸다. 직접 생성과 가져오기는 합치지 않는다.
조회는 `routine_list_viewed`·`routine_viewed`, 참여는 `routine_like_changed`·`routine_comment_submitted`,
공개 전환은 `routine_visibility_changed`로 측정한다. 같은 상태를 다시 저장한 것은 제품 편집으로 세지 않는다.
생성한 빈 루틴을 목록에서 다시 열어도 첫 제품을 추가할 때까지 생성 흐름을 유지한다.

기능에서 로그인 계속하기를 선택하면 `feature_login_requested`에 의도와 대상 ID를 남긴다.
기존 `login_started`·`login_succeeded`는 `login_source=routine|similar_products`와 같은 흐름 ID를
이어 받는다. `feature_intent_completed`는 로그인 성공 후 원래 대상에 원래 행동을 실제로 마쳤을 때만
한 번 보낸다. 다른 루틴의 가져오기·좋아요, 늦은 이전 로그인 응답은 완료로 세지 않는다.

유사템은 기준 제품 선택마다 새 흐름을 만들고 검색·파우치·인기 유사템 출처를 구분한다.
성공한 검색 후보와 유사템 결과는 0건도 남기며, 후보 선택과 제품 상세에는 기준·후보 제품 및
구성품 ID를 이어 준다. 가격 비교 불가 후보는 저렴한 후보 수에 넣지 않는다. 정렬은 기존
`sort_applied`에 화면과 기준 제품 ID를 추가한다.

유튜버 목록에서 제품 상세로 바로 가는 경로와 채널 상세에서 가는 경로를 모두 연결한다.
영상 목록 조회는 실제로 연 영상 탭의 결과 수를 남긴다. 썸네일·언급 시점·제품 시점 선택은
`youtube_video_play_requested`로 나누며 시작 시점은 밀리초를 보존한다. iframe의 재생 요청을
실제 시청·완주로 해석하지 않는다. 유튜브 외부 링크 이동도 별도 이벤트로 남긴다.

마크 필터는 시트를 열 때마다 새 `filter_flow_id`를 만들고 미리보기·적용·첫 결과·제품 상세에
전달한다. 같은 필터를 다시 적용해도 새 시도로 센다. 페이지·정렬만 바꾸면 문맥을 유지하지만
실제 조건이 달라지거나 30분이 지나면 연결하지 않는다. 닫힌 시트의 늦은 미리보기 응답은 제외한다.

서버의 `routine_change_committed`는 생성·가져오기·제품 변경이 커밋됐는지 확인하는 별도 진단이다.
클라이언트 완료 이벤트와 합산하거나 필수 퍼널의 단계로 쓰지 않는다. 추적 허용 상태의 실제 SDK가
준비됐을 때만 브라우저 분석 헤더를 전달하고, 서버에서는 인증된 회원 ID를 쓴다.
서버 전송은 `POSTHOG_PROJECT_TOKEN`·`POSTHOG_HOST`를 설정해야 켜지며, 분석 전송 실패는 API에 전파하지 않는다.
