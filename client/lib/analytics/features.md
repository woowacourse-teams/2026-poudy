# 새 기능 사용과 커뮤니티 참여

[PostHog 대시보드](https://us.posthog.com/project/562550/dashboard/2321306)는 사용 규모 지표 6개와
핵심 퍼널 5개로 구성한다. 저장·가져오기·작성 첫 제품 추가·혼합 로그인 복귀를 필수 성공 조건으로
삼지 않는다. 작성·가져오기·로그인 이벤트 자체는 필요할 때 진단할 수 있도록 유지한다.

## 사용 규모와 반복 이용

기본 기간은 최근 8주, 한국 시간 월요일 시작이다. `environment=production`, `$host=poudy.site`,
비봇, 프로젝트 테스트 계정 제외를 모든 지표에 동일하게 적용하며 웹·앱을 포함한다.
방문자는 해당 기간 운영 브라우저 이벤트가 관측된 고유 사용자다. 기능 이벤트만 관측된 사용자도
분모에 포함하므로 분자는 분모의 부분집합이다. 같은 주 같은 사람의 반복 행동은 사용자를 늘리지 않는다.

| 지표                             | 정의                                                                                                                 |
| -------------------------------- | -------------------------------------------------------------------------------------------------------------------- |
| 주간 새 기능 사용자 수·사용률    | 루틴·유사템·유튜버 콘텐츠·마크 필터의 사용자 수와 같은 주 전체 방문자 대비 비율. 내 루틴 관리와 커뮤니티도 별도 표시 |
| 기능별 다음 주 재이용률          | 이번 주 사용자가 다음 주에도 같은 기능을 사용한 비율. 첫 이용자 전용 리텐션이 아닌 반복 주간 코호트                  |
| 주간 커뮤니티 열람량             | 남의 루틴 상세 열람자 수·조회수·방문당 서로 다른 루틴 수                                                             |
| 주간 공개 루틴 작성자 수·게시 수 | 공개 생성 또는 비공개에서 공개로 변경한 고유 작성자·루틴 수. 같은 주 같은 루틴의 재공개는 중복 제외                  |
| 주간 커뮤니티 반응 참여율        | 같은 주 남의 루틴을 열람한 뒤 같은 루틴에 좋아요·댓글을 남긴 고유 사용자 비율. 좋아요 추가·댓글 횟수도 표시          |
| 유사템·마크 필터 결과 0건 비율   | 성공 결과 조회 중 0건 비율. 실패는 결과 0건으로 세지 않으며 조회 횟수 기준임을 표시                                  |

내 루틴은 내용이 있는 목록·상세 열람과 성공한 생성·제품 변경·가져오기·공개 변경·본인 댓글을 포함한다.
커뮤니티는 실제 노출된 피드 카드·남의 루틴 상세·좋아요 변경·남의 루틴 댓글을 포함한다.
둘 다 쓴 사람도 전체 루틴 사용률에서는 한 번만 센다. 작성·가져오기 없이 구경만 해도 이용이다.
루틴 상세의 `view_type=own`과 작성자 본인 댓글은 커뮤니티 상세·반응 집계에서 제외한다.

유사템은 성공한 비교 결과 조회, 마크 필터는 마크가 적용된 성공 목록 조회가 사용 기준이다.
0건도 사용에 포함한다. 유튜버는 내용이 있는 채널 목록·제품 콘텐츠·영상 목록 열람과 제품 선택·재생 요청을
포함한다. 빈 목록·요청 실패·필터 시트 열기만 한 경우는 실제 콘텐츠 이용으로 세지 않는다.

재이용률은 선택 기간의 마지막 관측 시각까지 다음 주 전체가 지나야 표시한다. 관측이 부족하거나
기간 끝에 걸친 코호트는 보수적으로 미성숙 상태로 두고 복귀 인원·비율을 비운다. 아직 끝나지 않은
주간 사용률에는 `partial_week`를 표시한다. 0명인 기능도 같은 주 방문자가 있으면 사용률 표에 남긴다.

## 필수 퍼널

모두 30분 내 순서 전환이고 고유 사용자 수와 첫 단계 대비 전환율을 표시한다. 같은 대상·탐색에서
실제로 연결된 흐름을 집계하고, 여러 번 시도한 사람도 각 단계에서 한 번만 센다. 방문 중 전환과
주간 이용·참여는 별도 지표이며, 퍼널 끝까지 가지 않아도 콘텐츠 열람은 이용에 포함한다.

| 제목                    | 단계·연결 기준                                                                             |
| ----------------------- | ------------------------------------------------------------------------------------------ |
| 커뮤니티 참여 전환율    | 남의 루틴 상세 → 좋아요 또는 댓글. 같은 사용자·루틴·SDK 세션. 본인 댓글과 좋아요 취소 제외 |
| 유사템 상세 탐색 전환율 | 기준 제품 선택 → 결과 조회 → 후보 상세. 같은 흐름·기준 제품. 결과 0건 포함                 |
| 유튜버 제품 탐색 전환율 | 제품 콘텐츠 열람 → 제품 선택 → 상세. 같은 흐름·채널. 전체 목록의 직접 제품 이동도 포함     |
| 유튜버 영상 재생 요청률 | 영상이 있는 목록 → 재생 요청. 같은 흐름·채널. 실제 시청·완주가 아님                        |
| 마크 필터 탐색 전환율   | 시트 열기 → 마크 적용 → 결과 조회 → 상세. 같은 필터 열기 ID. 결과 0건 포함                 |

공개 루틴 가져오기·루틴 작성 첫 제품 추가·루틴/유사템 혼합 로그인 복귀 퍼널 3개는 복구 가능한
삭제로 정리했다. 기존 탐색 퍼널 4개는 링크를 유지하며 정의를 교체했다. 이벤트와 쿼리·인사이트 ID는
[feature-insights.json](./feature-insights.json), 콘텐츠 노출·작성자 판정은 [usage-events.md](./usage-events.md)에 둔다.

## 수집과 검증

`analytics_schema_version=4`와 기존 기능 흐름 1시간·제품 유입 30분의 보관 계약을 유지한다.
루틴 이름·메모·댓글·닉네임·프로필 주소를 전송하지 않는다. 생성·수정·반응은 API 성공 뒤 기록한다.
새 이벤트 정의는 실제 배포 수집 전까지 `verified=false`다. 수집 전 0을 미사용으로 해석하지 않으며
운영에 가짜 이벤트를 보내지 않는다. 서버 `routine_change_committed`는 별도 진단으로만 유지하고
클라이언트 사용량·퍼널에 합산하지 않는다. 서버 진단은 기존 선택 환경 변수로 활성화한다.
