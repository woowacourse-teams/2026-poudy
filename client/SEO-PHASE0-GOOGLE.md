## 우선순위 제안

1. **미색인 URL과 사이트맵 처리 상태 대조.** 22,507건과 69건의 예시 URL을 받아 현재 사이트맵·URL 종류·중복 변형을 분류한다. 사이트맵 마지막 읽은 날짜·인식한 URL 수, 홈/제품/성분의 URL 검사에서 마지막 크롤링·선택된 canonical을 확인한다. 서버 변경 전 원인을 좁히는 작업이다.
2. **발견 경로와 SSR 보완.** 성분 검색 fallback, 목록 page 처리/다음 링크, 성분→제품 링크와 /products 정책을 함께 설계한다. 조건 조합 URL을 무제한 허용하지 않도록 공개 허브와 필터 목록의 역할을 정한다.
3. **기존 개선의 운영 반영·검증.** #478의 이미 구현된 제목·구조화 데이터 등을 확인한다. 미색인 해결을 JSON-LD만으로 설명하지 않는다.
4. **접속 실패와 중복 URL 확인.** 연결 불가·404·www 오류의 예시와 날짜를 확보해 재현한다. 의도된 404·301을 오류처럼 없애지 않는다.
5. **콘텐츠·메타 보강.** 중요한 제품/성분의 고유한 설명·사실·출처·관련 링크를 먼저 보강한다. llms.txt·블로그 확장은 후순위다.

## 추가 자료와 측정

필수 추가 자료는 (1) 미색인 사유별 URL 예시 CSV, (2) 사이트맵 처리 화면, (3) 홈·대표 제품 3개·성분 3개의 Google URL 검사 결과다. 크롤링 연결 실패와 제품 스니펫의 문제 URL은 후속 원인 확인에 필요하다. 네이버 자료가 없어도 Google 진단·개선은 진행할 수 있다.

변경 배포일을 D0로 기록하고 D0+14일에 재수집·색인 변화를, D0+28일에 노출·클릭 변화를 비교한다. 9월 26일 배포한다면 각각 10월 10일과 10월 24일이다. 아직 배포하지 않았으므로 고정 일정이나 알림을 예약하지 않았다. 동일 기간·요일로 비교하고 최근 3일의 집계 지연을 제외한다. 22,000개 전체보다 현재 사이트맵의 중요한 제품·성분 표본을 별도로 추적한다.

현재 CSV에서 확인하지 못한 것: 미색인 URL 구성, 현재 사이트맵별 색인 수, 선택된 canonical, 연결 실패 원인, 실제 Core Web Vitals, 네이버 색인, 실제 AI 답변 인용. 이번 Phase 0 완료는 기술 진단 완료를 뜻하며 SEO 성과 개선이나 전체 스킬 완료를 뜻하지 않는다.

## 공식 해석 기준

- [Google 색인 보고서](https://support.google.com/webmasters/answer/7440203?hl=en): 알려진 URL과 현재 사이트맵을 구분하고 미색인 사유별로 판단한다.
- [Google 페이지네이션 가이드](https://developers.google.com/search/docs/specialty/ecommerce/pagination-and-incremental-page-loading): 버튼·스크롤에 의존하지 않는 발견 경로, 순차 링크, 각 페이지의 URL과 canonical.
- [robots.txt 안내](https://developers.google.com/search/docs/crawling-indexing/robots/intro): 크롤링 차단과 색인 제외는 다르다.
- [Search Console 집계 차이](https://support.google.com/webmasters/answer/17010575?hl=en): 익명 검색어와 집계 방식에 따른 표·차트 차이.
