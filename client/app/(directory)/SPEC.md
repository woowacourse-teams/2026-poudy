### 공통

- 레일은 `Tabs`의 `rail` 모양입니다. 세로 `tablist`이고, ↑↓와 Home·End로 옮기면 지연 없이 바로 패널이 바뀝니다(A11Y D04 자동 전환). 카테고리는 대분류마다 패널을 미리 그려 두고 감춥니다. 검색 로봇이 받는 첫 HTML에도 모든 소분류 링크가 남습니다.
- 레일과 목록은 각자 스크롤하고, 끝에 닿은 스크롤이 화면 전체로 번지지 않게 막습니다. 두 단의 높이는 화면에서 하단 내비를 뺀 높이를 상단 내비와 전환 탭이 먼저 쓰고 남은 만큼입니다.
- 행 전체가 링크이고 높이는 52입니다. 스크롤 목록의 행이므로 눌림은 80ms 기다렸다가 켭니다(STATE S09). hover와 눌림에는 면을 `ui-hover-on-surface`로 칠하고, 수량 글자를 `ui-text-secondary`로, 로고 원을 흰 면으로 함께 바꿉니다(S10).
- 레일 칸을 고르고 풀 때와 탭을 옮길 때는 전환 효과 없이 바로 바꿉니다(MOTION M03, 방향키로 반복하는 동작).
- 전환 탭을 누르면 밑줄이 이전 탭에서 새 탭으로 미끄러집니다. 검색 모드 탭(#735)과 같이 `TabNav`의 `transitionName`(View Transition)을 쓰고, 누른 자리에서 먼저 옮깁니다. 움직임 줄이기 설정이면 옮기지 않고 바로 그립니다.

### 접근성과 반응형

- 상단 내비는 큰 제목 `카테고리`이고, 문서의 대표 제목(`h1`)입니다. 전환 탭은 `TabNav`이고 지금 화면의 링크에 `aria-current="page"`를 답니다.
- 패널마다 보이지 않는 제목(`h2`)과 설명을 두어, 보조 기술이 지금 어떤 목록인지 알립니다. 아이콘은 모두 보조 기술에서 감춥니다.
- 레일 폭은 화면 폭이 390 이상이면 132, 360 이상이면 104, 그보다 좁으면 96이고, 기기 글자 크기를 따라 함께 커집니다. 레일 이름은 두 줄까지 허용합니다(A11Y D08). 390보다 좁으면 `베이스메이크업`처럼 띄어 쓴 곳이 없는 이름이 칸을 넘치므로, 넘칠 때만 낱말 안에서 줄을 바꿉니다. 390 이상의 132는 이 이름도 한 줄에 들어가고 오른쪽 여백 16이 남는 폭입니다.
- 레일과 목록은 스크롤 칸이라 바깥으로 그린 포커스 링이 좌우에서 잘립니다. 레일 칸과 목록 행의 포커스 링은 칸 안쪽에 그립니다.
- 글자를 키워 두 단이 들어가지 않으면 레일을 목록 위의 가로 줄로 옮깁니다. 이때도 역할은 세로 `tablist`로 남고, 방향키는 ↑↓입니다.
- 320·360·390 폭에서 가로로 넘치지 않아야 하고, 글자를 200%로 키워도 잘리는 곳이 없어야 합니다.

## 라우팅

| 경로          | 화면 | 파일                                  |
| ------------- | ---- | ------------------------------------- |
| `/categories` | S27  | `app/(directory)/categories/page.tsx` |
| `/brands`     | S29  | `app/(directory)/brands/page.tsx`     |

두 화면은 `app/(directory)/layout.tsx`의 상단 내비와 전환 탭을 함께 씁니다. 쿼리 파라미터는 없고, 고른 레일 칸은 주소에 남기지 않습니다.

## 부품 교체

| 옛 부품                                                 | 디자인 시스템 부품                                                           |
| ------------------------------------------------------- | ---------------------------------------------------------------------------- |
| `components/ui/TopBar`(`root`)                          | `TopBar`(`large`)                                                            |
| `DirectoryTabs`의 직접 만든 밑줄 탭과 `StickyBar`       | `TabNav` + `TabNavItem`                                                      |
| `DirectoryList`의 `<button aria-current>` 레일          | `Tabs`(`rail`) + `TabList`·`Tab`·`TabPanel`(`TabPanel`에 `keepMounted` 추가) |
| `components/ui/icons/Icon`                              | `Icon`(`scalable`)                                                           |
| `press.ts`의 `PRESS_SURFACE`, `active:`·`hover:` 클래스 | `usePressable` + `fb-row`                                                    |
| 없음(로딩·오류 화면)                                    | `Skeleton`, `ErrorState`(screen)                                             |

`DirectoryList`는 디렉터리만 쓰므로 `components/directory`로 옮깁니다. `BrandLogo`는 브랜드 상세도 쓰므로 자리는 그대로 두고 인라인 스타일만 토큰으로 바꿉니다. 옛 `TopBar`와 `StickyBar`는 다른 화면이 아직 쓰므로 지우지 않습니다(#743). 대상 경로는 `eslint.config.mjs`의 `tokenStrictFiles`에 넣어 디자인 토큰 린트를 오류로 올립니다.

## PostHog 이벤트

지금 화면이 보내는 이벤트입니다. 이번 작업에서 새로 만들거나 바꾸는 이벤트는 없습니다.

| 이벤트              | 보내는 때                                                        | 속성                                                                               |
| ------------------- | ---------------------------------------------------------------- | ---------------------------------------------------------------------------------- |
| `page_viewed`       | `/categories`, `/brands`에 들어올 때(`AnalyticsProvider`)        | `page: "category"` 또는 `page: "brand"`                                            |
| `category_selected` | 카테고리 디렉터리에서 소분류 행이나 `{대분류} 전체` 행을 누를 때 | `category_id`, `category_name`, `origin_surface: "category"`                       |
| `brand_selected`    | 브랜드 디렉터리에서 브랜드 행을 누를 때                          | `brand_id`, `brand_name`, `index_label`(그때 고른 레일 칸: `전체`, `ㄱ`, `A-Z` 등) |
| `error_occurred`    | 화면이 무너져 오류 경계가 잡을 때(`reportBoundaryError`)         | `error_code`, `surface`                                                            |

레일 칸을 고르는 동작은 화면 안의 패널 전환이라 따로 이벤트를 보내지 않습니다. 어느 칸에서 골랐는지는 `brand_selected`의 `index_label`이 남깁니다.
