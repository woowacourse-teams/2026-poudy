## 요구사항

### 선반(`/shelf`)

| 상태        | 동작                                                                                                                           |
| ----------- | ------------------------------------------------------------------------------------------------------------------------------ |
| 불러오는 중 | 0.3초가 지나도 응답이 없으면 성분 카드, 보기 필터, 제품 행 자리에 스켈레톤을 둡니다. 기다리는 영역에 `aria-busy`를 답니다.     |
| 로그인 전   | 공감 제목, 좋은 점 셋, '선반 기능 자세히 보기' 줄을 두고, [로그인하고 내 선반 만들기]를 하단 내비 위 행동 영역에 둡니다(S54a). |
| 관리자 세션 | 관리자 세션 안내를 둡니다.                                                                                                     |
| 오류        | 본문 가운데에 화면 오류(`ErrorState` screen)와 [다시 시도]를 둡니다. 상단 내비와 하단 내비는 남깁니다(S51).                    |
| 빈 선반     | 가운데에 빈 상태 안내와 쓰는 순서 세 단계, [제품 추가하기], '선반은 어떻게 쓰나요?'를 둡니다(S54b).                            |
| 제품 있음   | 성분 카드(안 맞은 제품이 있을 때), 보기 필터, 제품 목록을 둡니다(S52). 성분 카드는 보기 필터를 바꿔도 남깁니다.                |

- 상단 내비는 큰 제목 내비입니다. 오른쪽에 도움말(`help-circle`, 기능 설명 시트를 엽니다)과 추가(`plus`, `/shelf/add`로 갑니다)를 둡니다. 로그인 전에는 둘 다 숨깁니다(S54a).
- 제품이 담긴 채 선반에 처음 들어오면 기능 설명 시트(S54c)를 한 번 띄웁니다. 빈 선반과 로그인 전에는 본문이 안내를 맡아 띄우지 않습니다. 한 번 띄웠는지는 기기에 남기고, 그 뒤에는 도움말 버튼으로만 엽니다.
- 보기 필터는 상단 내비(64) 바로 아래에 붙습니다. 제품이 있으면 붙은 줄이 아래 선을 맡고, 상단 내비는 선을 긋지 않습니다.
- 제품 메뉴(S52d)에서 옮기기·평가 지우기를 하면 결과를 반영한 뒤 '되돌리기'가 있는 토스트를 띄웁니다(S53g). 되돌리면 앞의 평가와 사용 상태로 돌려놓습니다.
- 선반에서 빼면 확인 시트(S52f)를 거칩니다. 뺀 뒤에도 되돌리기 토스트를 띄우고, 되돌리면 같은 사용 상태와 평가로 다시 담습니다.
- 저장·옮기기·빼기에 실패하면 토스트로 알립니다. 평가 시트는 열어 둔 채로 다시 누를 수 있게 합니다.
- 성분 칩을 누르면 그 성분의 설명(`/ingredients/{id}?from=shelf`)으로 갑니다.
- 성분 카드는 머리(제목 · '필터 관리 ›') → 아직 제외하지 않은 성분 → 검색에서 제외 중 → 고르기 버튼 → 아래 안내(피부 타입 · 정확도) 순서입니다. 찾은 성분이 없으면 머리 아래에 '안 맞았던 제품에서 주의 성분을 찾지 못했어요.'만 둡니다(S53m).
- 고르기 버튼은 아직 제외한 성분이 없을 때 '검색에서 제외할 성분 고르기', 신규 성분이 생겼을 때 '검색에서 제외할 신규 성분 고르기'입니다. 안 맞은 제품이 하나뿐이면 두지 않습니다(S53a · S53i).
- 평가 시트는 머리에 ✕ 를 두지 않습니다. 딤을 누르거나 끌어 내리거나 Esc 로 닫습니다(S52e · S52i).

### 제품 추가(`/shelf/add`)

- 자동완성에서 [추가]를 고르면 아직 담지 않고 평가 시트만 엽니다(S52i). '지금 쓰고 있나요?'는 필수라 '네'를 미리 골라 둡니다.
- 시트에서 [나중에 할게요] · [다음] · [평가 저장]을 눌러야 담깁니다. 고른 사용 상태와 1단계 답을 함께 보내 한 번에 담고, 2단계의 사용감은 담은 제품의 평가로 고칩니다. 담은 행은 '선반에 있음'이 됩니다.
- 시트를 그냥 닫으면(딤 · 끌어 내리기 · Esc) 담기를 취소한 것으로 보고, 행은 [추가]로 남깁니다.
- [나중에 할게요]로 담으면 '선반에 저장했어요. 평가는 선반에서 언제든 할 수 있어요' 토스트에 [되돌리기]를 둡니다(S52j). 되돌리면 담은 제품을 뺍니다.
- 담기 전에 단계 수를 정할 수 있도록, 선반 자동완성 응답에 사용감 평가 여부(`sensorySupported`)가 들어 있습니다.
- 담지 못하면 토스트로 알립니다. 자동완성을 받지 못하면 목록 자리에 섹션 오류(`ErrorState` section)와 [다시 시도]를 둡니다.
- 등록 요청 시트(S53h)는 머리에 뒤로·제목·설명을 둡니다. 보내면 시트를 닫고 토스트로 알립니다. 보내지 못하면 제품명 칸 아래에 오류를 둡니다.
- 아래의 등록 요청 줄은 하단 행동 영역이 아니라 명세 S52g의 회색 줄입니다. 그래서 `BottomActionBar`로 바꾸지 않습니다.

### 검색에서 제외할 성분 고르기(`/shelf/filter`)

- 불러오는 중에는 제목과 성분 행 자리에 스켈레톤을, 실패하면 화면 오류와 [다시 시도]를 둡니다.
- 아래 버튼은 하단 행동 영역(`BottomActionBar`, 화면 끝)입니다. 고른 성분이 없으면 버튼을 막고 이유를 안내 줄에 적습니다.
- 넣으면 선반으로 돌아가 토스트를 띄웁니다. 처음 넣으면 '성분 N개를 나만의 필터에 넣었어요'(S53e), 이미 제외 중인 성분이 있었으면 '성분 N개를 나만의 필터에 더 넣었어요'(S53k)입니다. 명세의 두 프레임 모두 [되돌리기]가 없어서 행동 버튼을 두지 않습니다. 넣은 성분은 나만의 필터에서 뺄 수 있습니다.
- 넣지 못하면 토스트로 알리고 화면에 남습니다.

### 소개 페이지(`/shelf/guide`)

- 하위 상단 내비와 하단 행동 영역(화면 끝) '제품 추가하러 가기'를 둡니다.

### 접근성

- 시트는 패키지 `BottomSheet`·`ConfirmSheet`가 포커스 가두기, Esc·딤·끌어내리기 닫기, 연 요소로 포커스 돌려주기를 맡습니다(A11Y D02).
- 제품 메뉴와 평가 시트의 머리는 제품 썸네일을 함께 보여 주므로, 시트 제목(`h2`) 안에 썸네일과 제품 이름을 함께 둡니다. 썸네일 그림은 낭독에서 뺍니다.
- 토스트의 [되돌리기]를 누른 뒤에는 포커스를 원래 컨트롤로 돌려줍니다. 컨트롤이 사라졌으면 제품 목록 영역으로 돌려줍니다(A11Y D10).
- 아이콘 버튼은 대상이 드러나는 이름을 씁니다. 예: '선반 기능 설명', '제품 추가', '{제품명} 메뉴'.

### 반응형

- 320·360·390 폭에서 가로로 넘치지 않아야 합니다. 글자를 200%로 키워도 제목과 버튼 글자가 잘리지 않아야 합니다.

## 바꿀 옛 부품

| 옛 부품                           | 쓸 디자인 시스템 부품                                           |
| --------------------------------- | --------------------------------------------------------------- |
| `components/ui/TopBar` (root·sub) | `TopBar`(`large`), 하위 화면은 `SubTopBar` + `Screen`(document) |
| `components/ui/StickyBar`         | `Screen` 안의 sticky 줄. 붙었는지는 패키지 표식으로 판단합니다  |
| `components/ui/BottomSheet`       | `BottomSheet` + `BottomSheetHeader`·`Body`·`Footer`             |
| 빼기 확인에 쓴 `BottomSheet`      | `ConfirmSheet`                                                  |
| `components/ui/icons/Icon`        | `Icon`(패키지에 있는 그림만. 없는 그림은 아래 '남는 것' 참고)   |
| 직접 그린 하단 고정 버튼          | `BottomActionBar`(screen-end)                                   |
| 문구만 있던 불러오기 실패         | `ErrorState`(screen·section)                                    |
| 빈 본문으로 둔 불러오는 중        | `Skeleton` + `useDelayedFlag`                                   |
| 버튼 위 실패 문구와 미뤄 둔 알림  | `useToast`(앱 레이아웃의 `ToastProvider`)                       |
| S52i 시트 머리 위 저장 안내       | `Notice`                                                        |

토스트는 앱에 하나만 둡니다. 루트 레이아웃이 `ToastProvider`로 본문을 감쌉니다. 띄우는 높이(`--toast-offset`)는 `globals.css`가 화면 아래에 붙은 영역을 보고 CSS의 `:has()`로 정합니다.

| 화면 아래에 붙은 영역                            | `--toast-offset`                       |
| ------------------------------------------------ | -------------------------------------- |
| 하단 내비(`[data-bottom-navigation]`)            | `--bottom-navigation-height`           |
| 하단 행동 영역(`[data-toast-offset=action-bar]`) | 81px(선 1 + 위 12 + 버튼 56 + 아래 12) |
| 없음                                             | 0                                      |

### 남는 것

- 패키지 `Icon`에 아직 없는 그림(`pencil`, `eraser`, `filter`, `flask-solid`, `minus`, `zoom-exclamation`, 외곽선 `thumb-up`·`thumb-down`)은 옛 `Icon`을 그대로 씁니다. 패키지에 그림이 들어오면 바꿉니다.
- 등록 요청 시트의 전성분 사진 첨부(S53h)는 서버의 등록 요청 API가 사진을 받지 않아 넣지 않습니다.

- `ingredient_viewed`의 `entry_point`에 `shelf`를 더합니다(`IngredientEntryPoint`, `TrackIngredientView`의 허용 목록). 값이 없으면 `product_detail`로 기록되어 선반에서 들어온 방문이 제품 상세에서 들어온 방문으로 섞이기 때문입니다.
- 이름과 기존 속성은 바꾸지 않습니다.
- 담기·평가·옮기기·빼기·되돌리기 같은 선반 행동 이벤트는 이번 범위에서 만들지 않습니다. 필요하면 따로 이슈를 열어 이름과 속성을 정합니다.
