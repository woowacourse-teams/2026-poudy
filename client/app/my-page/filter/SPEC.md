## 요구사항

| 상태        | 동작                                                                                                                                                                                                                                                                  |
| ----------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 불러오는 중 | 0.3초가 지나도 응답이 없으면 묶음 머리와 성분 행 자리에 스켈레톤을 둡니다. 기다리는 영역에 `aria-busy`를 답니다. 10초가 지나도 오지 않으면 스켈레톤 위에 '시간이 조금 걸리고 있어요'와 [다시 시도]를 함께 보이고, [다시 시도]를 누르면 다시 요청합니다(FEEDBACK F02). |
| 관리자 세션 | 관리자 세션 안내를 둡니다.                                                                                                                                                                                                                                            |
| 오류        | 본문 가운데에 화면 오류(`ErrorState` screen)와 [다시 시도]를 둡니다(S51).                                                                                                                                                                                             |
| 비어 있음   | 남은 자리의 가운데에 빈 상태(`EmptyState`)를 둡니다. 파우치에서 성분을 찾는다는 안내와 [파우치 보기]를 둡니다(S55j-2).                                                                                                                                                |
| 성분 있음   | '검색에서 제외 중' 묶음, '파우치에서 찾았지만 넣지 않은 성분' 묶음, 파우치 안내를 둡니다.                                                                                                                                                                             |

- 성분을 빼면 행을 바로 지우고, 서버가 받으면 '{성분}을 나만의 필터에서 뺐어요' 토스트와 [되돌리기]를 띄웁니다(S55j-1).
- 성분을 넣으면 '{성분}을 나만의 필터에 넣었어요' 토스트와 [되돌리기]를 띄웁니다. 명세 프레임은 따로 없고, S55j-1과 같은 토스트입니다.
- 토스트의 [되돌리기]는 자리가 있으면 문장 옆에 두고, 문장이 좁아지면 문장 아래로 내립니다(디자인 시스템 `Toast`).
- 두 토스트의 성분명은 12자(또는 첫 '/'까지)로 줄이고, 조사는 원래 이름의 받침을 따릅니다(CONTENT W06 예외 ④, `withJosaShort`).
- 빼거나 넣지 못하면 행동 없는 토스트로 알립니다.
- 토스트는 앱 레이아웃의 `ToastProvider` 하나가 띄웁니다. 이 화면에는 하단 고정 영역이 없으므로 화면 아래에서 12 위에 뜹니다.

### 접근성

- [되돌리기]를 누르면 포커스를 성분 목록 영역으로 돌려줍니다. 누른 행의 버튼은 이미 사라졌거나 다른 묶음으로 옮겨 갔기 때문입니다(A11Y D10).
- 빼기·넣기 버튼은 '{성분} 필터에서 빼기', '{성분} 필터에 넣기'처럼 대상이 드러나는 이름을 씁니다.

### 반응형

- 320·360·390 폭에서 가로로 넘치지 않아야 합니다. 글자를 200%로 키워도 성분 이름과 버튼이 겹치지 않아야 합니다.

## PostHog 이벤트

이 화면은 화면 단위 이벤트(`page_viewed`)를 보내지 않습니다. `AnalyticsProvider`의 `pageOf`가 `/my-page/filter`를 화면 이름에 넣지 않았기 때문입니다.

| 이벤트       | 언제 보내나                                                  | 속성              | 이번 변경 |
| ------------ | ------------------------------------------------------------ | ----------------- | --------- |
| `$pageview`  | 화면에 들어올 때(PostHog `capture_pageview: history_change`) | PostHog 기본 속성 | 없음      |
| `$pageleave` | 화면을 떠날 때                                               | PostHog 기본 속성 | 없음      |

- 새로 만들거나 바꾸는 이벤트는 없습니다. 빼기·넣기·되돌리기 이벤트가 필요하면 따로 이슈를 열어 정합니다.
