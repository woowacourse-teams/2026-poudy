## 요구사항

### 화면 구성

- 하위 상단 내비(제목 '프로필 수정') 아래에 사진과 닉네임을 차례로 두고, 맨 아래에 하단 행동 영역(`BottomActionBar`, 화면 끝)을 둡니다.
- 본문 위아래 여백은 24이고(가입 화면 S38과 같습니다), 사진과 닉네임 사이는 32입니다.

### 상태

| 상태      | 동작                                                                                                                    |
| --------- | ----------------------------------------------------------------------------------------------------------------------- |
| 로딩      | 스켈레톤을 보이고 본문에 `aria-busy`를 답니다. 10초가 지나면 스켈레톤 위에 안내와 [다시 시도]를 보입니다(FEEDBACK F02). |
| 오류      | 회원 정보를 읽지 못하면 `ErrorState`(screen)와 [다시 시도]를 보여 주고, 하단 행동 영역은 두지 않습니다.                 |
| 로그인 전 | 돌아올 주소를 기억하고 로그인 화면으로 보냅니다.                                                                        |
| 관리자    | `AdminSessionNotice`를 보여 줍니다.                                                                                     |

### 사진

- 사진을 누르면 고르거나 바꿉니다. 사진이 있으면 오른쪽 위 ✕로 지웁니다.
- 오른쪽 아래 배지는 사진이 없으면 `photo-plus`, 있으면 `photo-edit`입니다. 올리는 중에는 숨기고, 실패하면 다시 올리기 표지로 바꿉니다.
- 배지에는 그림자를 두지 않습니다. 테두리가 이미 사진과 구분해 줍니다(SHAPE E03).
- 올리지 못하면 빨간 테두리와 문구로 알리고, 사진을 누르면 다시 올립니다.
- 형식이나 용량이 맞지 않는 사진은 올리지 않고 사진 아래 문구로 이유를 알립니다.

### 닉네임

- 입력하는 동안 형식을 검사하고, 바꾼 닉네임은 입력이 멈춘 뒤 중복을 확인합니다.
- 칸 아래 안내는 규칙, '중복을 확인하고 있어요.', '사용할 수 있는 닉네임이에요.' 중 하나입니다.

### 저장 버튼

화면 하단 버튼은 막힌 이유를 버튼 글자로 말합니다(FEEDBACK F06, STATE S06, 2026-11-05 결정). 막힌 동안에도 포커스는 남습니다(`aria-disabled`).

| 조건                | 버튼 글자              |
| ------------------- | ---------------------- |
| 바꾼 내용이 없음    | 바꾼 내용이 없어요     |
| 사진을 올리는 중    | 사진을 올리는 중이에요 |
| 사진을 올리지 못함  | 사진을 확인해 주세요   |
| 닉네임을 쓸 수 없음 | 닉네임을 확인해 주세요 |
| 그 밖의 경우        | 저장                   |

- 중복을 확인하는 동안에는 칸 아래 안내가 이유를 말하므로 글자를 '저장'으로 두고 막습니다.
- 저장하면 이전 화면으로 돌아가고, 기록이 없으면 `/my-page`로 보냅니다.
- 닉네임이 충돌하면 칸에 오류를 보이고, 그 밖의 실패는 토스트로 알리고 입력을 남깁니다.
