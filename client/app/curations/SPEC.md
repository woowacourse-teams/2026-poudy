## 화면 구성

- **상단 내비:** 디자인 시스템 `TopBar`(`sub`)를 씁니다. 뒤로가기, 가운데 기획전 제목, 오른쪽 공유 버튼으로 구성합니다. 스크롤해도 위에 붙어 있습니다.
  - 사이트 안에서 온 기록이 있으면 이전 화면으로 돌아갑니다. 공유 링크로 바로 들어와 기록이 없으면 `홈으로` 링크가 대신 섭니다.
  - 공유는 앱에서는 공유 시트를 열고, 웹에서는 주소를 복사한 뒤 `주소를 복사했어요` 토스트를 띄웁니다(FEEDBACK F04).
- **본문:** 서버가 준 순서대로 블록을 쌓고, 블록마다 받은 위아래 여백을 그대로 적습니다.
  - 이미지 블록은 화면 폭을 채우고, 그림 속 문구는 `figcaption`에 낭독용으로 남깁니다.
  - 제품 블록은 거터 안쪽에 홈과 같은 3열(360 미만은 2열) 격자를 둡니다.
  - 필터 제품 블록은 홈과 같은 칩 줄을 위에 두고, 고른 필터에 맞는 제품만 보여 줍니다.
  - 제품 링크 블록은 거터 안쪽의 검은 버튼 모양 링크입니다(BTN · Primary, 높이 48).
- **다른 이야기도 준비했어요:** 지금 기획전을 뺀 큐레이션을 높이 128 카드로 세로로 쌓습니다. 카드는 안쪽 여백 20, 모서리 `rounded-2xl`, 제목 `text-block`, 설명 `text-label`입니다.
- 끝에 40을 비우고 푸터를 둡니다.

## 상태별 동작

| 상태               | 동작                                                                                    |
| ------------------ | --------------------------------------------------------------------------------------- |
| 기본               | 서버가 본문과 다른 큐레이션 목록을 함께 받아 그려서 보냅니다                            |
| 불러오는 중        | 서버가 다 그린 뒤 보내므로 화면에 따로 두지 않습니다                                    |
| 빈 상태            | 필터에 맞는 제품이 없으면 `EmptyState`로 `고른 조건에 맞는 제품이 없어요`를 보여 줍니다 |
| 없는 기획전        | `notFound()`로 없는 주소 화면(S51c)을 그립니다                                          |
| 본문 오류          | 오류를 그대로 던져 화면 오류(S51)를 그립니다                                            |
| 다른 큐레이션 오류 | 목록만 비우고 본문은 그대로 보여 줍니다                                                 |

## 접근성

- 바의 기획전 제목이 이 화면의 `h1`입니다. `다른 이야기도 준비했어요`는 `h2`입니다.
- 공유 버튼의 이름은 `공유하기`입니다. 뒤로가기는 `이전 화면` 또는 `홈으로`라고 읽습니다.
- 이미지 블록의 `alt`는 서버의 `altText`를 쓰고, 없으면 `alt=""`로 둡니다.
- 카드와 칩의 포커스 링은 디자인 시스템 규칙(STATE S06)을 따릅니다.

## 반응형

- 거터는 360 미만 12, 그 이상 16입니다. 제품 격자는 360 미만에서 2열입니다.
- 사진의 `sizes`는 실제로 그려지는 폭을 적습니다. 이미지 블록은 `(min-width: 448px) 448px, 100vw`, 다른 큐레이션 카드는 거터를 뺀 폭입니다.

## 명세와 다르게 둔 곳

- **바 제목 크기:** S20b의 바는 제목을 `text-block`(18)으로 그렸지만, 컴포넌트 `ZdlT8`은 `text-bar`(17)입니다. 다른 하위 화면과 같도록 컴포넌트를 따릅니다.
- **블록 여백:** 관리자가 블록마다 정한 숫자라 토큰으로 옮길 수 없습니다. 기한이 있는 예외 꼬리표를 달고 inline style로 둡니다.
