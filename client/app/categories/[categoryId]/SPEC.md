## 화면 구성

위에서 아래로 다음 순서로 쌓습니다.

1. 탐색 앱바: `TopBar variant="explore" align="start"`를 씁니다. 높이는 56이고, 제목(카테고리 이름)은 왼쪽에 둡니다. 바 아래 선은 필터 칩 줄이 맡으므로 바에서는 끕니다(`edge={false}`).
2. 카테고리 가로 트랙(명세 `APP · 카테고리 가로 트랙`): `Tabs variant="underline" layout="scroll"`과 `Tab asChild`(Link)로 그립니다. 첫 탭은 `전체`이고 대분류 화면으로 이동합니다. 고른 탭은 15/700에 2px 밑줄을, 나머지는 15/500 `text-secondary`를 씁니다. 트랙은 스크롤을 따라 올라갑니다.
3. 제품 목록: `TabPanel` 안에 공유 부품 `ProductList`(#736)를 둡니다. 필터 칩 줄은 앱바 바로 아래(56)에 붙습니다.

카테고리 칩은 숨깁니다. 이동은 탭이 맡고 필터는 칩이 맡는다는 명세(`sFtS9` context)를 따릅니다.

## 상태별 동작

| 상태      | 동작                                                                                                                                                                                   |
| --------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 기본      | 앱바와 탭은 서버가 먼저 그리고, 제품 목록은 스트리밍합니다                                                                                                                             |
| 로딩      | 목록 자리에 `ProductListSkeleton`을 둡니다. 앱바와 탭은 기다리지 않습니다                                                                                                              |
| 빈 상태   | 사용자가 건 조건이 있으면 '조건에 맞는 제품이 없어요'와 [조건 모두 지우기]를 보여 줍니다. 조건이 없으면 '아직 이 카테고리에 등록된 제품이 없어요'와 [카테고리 전체 보기]를 보여 줍니다 |
| 없는 주소 | 숫자가 아니거나 목록에 없는 id이면 `notFound()`를 부르고 S51g를 그립니다                                                                                                               |
| 오류      | 목록 조회가 실패하면 공유 부품이 다시 요청합니다. 화면 전체가 실패하면 `app/error.tsx`가 그립니다                                                                                      |

## 접근성

- 앱바의 제목은 문서의 대표 제목(`h1`)입니다.
- 탭 묶음의 이름은 `같은 분류의 카테고리`입니다. 고른 탭에는 `aria-selected="true"`가 붙고, 방향키와 Home·End로 탭을 옮기면 그 화면으로 이동합니다.
- 뒤로가기의 이름은 `이전 화면`입니다. 이 사이트 안에서 쌓인 방문 기록이 없으면 `카테고리 전체`라는 이름의 링크가 되어 `/categories`로 이동합니다.

## 반응형

- 320·360·390 폭에서 가로로 넘치지 않습니다. 탭이 넘치면 탭 줄만 가로로 스크롤합니다.
- 글자를 200%로 키워도 앱바 제목은 한 줄로 줄이고(`truncate`), 탭은 높이를 늘려 글자를 담습니다.
