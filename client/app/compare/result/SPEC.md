# 제품 비교와 비교함

- 디자인: `client/design/poudy-ui.pen`의 `시안 v2 · 제품 비교 · 비교함` 프레임(`Xtx0e`)
- API: `GET /api/products/comparison` (#1077, #1091)

제품 상세에서 제품을 비교함에 담고, 담은 제품을 세 칸에 나란히 놓아 비교합니다.

## 명세 프레임

| 프레임 id | 화면                                 | 구현한 곳                                 |
| --------- | ------------------------------------ | ----------------------------------------- |
| `eodMD`   | V1 제품 상세 · 담기 전, 비교함 1개   | `ComparisonToggle`, `ComparisonTrayBar`   |
| `FL4vB`   | V1-b 제품 상세 · 담은 뒤, 비교함 2개 | `ComparisonToggle`, `ComparisonTrayBar`   |
| `E0W9Zs`  | V1-c 제품 상세 · 띠를 접은 알약      | `ComparisonTrayBar`                       |

| `IZJCx`   | V3-s 스크롤한 뒤의 줄어든 머리       | `ProductComparisonScreen`의 `CompactHead` |
| `A74p91`  | V3-a 2개, 빈 칸의 제품 담기          | `ProductComparisonScreen`의 `AddSlot`     |

## 동작

- 비교함은 이 기기의 `localStorage`에만 저장합니다. 계정에 저장하는 API가 아직 없기 때문입니다.
- 최대 3개까지 담습니다. 3개가 찼는데 담으려고 하면 담지 않고 토스트와 `비교함 보기`를 보여 줍니다.
- 띠의 `비교하기`는 2개 이상 담았을 때만 누를 수 있습니다.
- 띠의 ×는 띠를 알약으로 접기만 하고, 담은 제품은 비우지 않습니다.
- 제품 상세의 저장 버튼 줄과 하단 고정 바는 기존 동작을 유지합니다. 하단 바가 없을 때는 띠가 화면 끝에 붙고, 하단 바가 올라오면 함께 올라갑니다.
- 비교 화면에서 1개만 남으면 남은 제품의 상세로 옮기고, 방문 기록을 바꿔 뒤로가기로 돌아오지 않게 합니다.
- 고른 구성품이 없어졌으면(`PRODUCT_PART_NOT_FOUND`) 첫 구성품으로 되돌려 다시 받습니다. 담은 제품이 없어졌으면(`PRODUCT_NOT_FOUND`) 비교함을 비우도록 안내합니다.

## 항목

| 항목        | 값과 표시 규칙                                                                                            |
| ----------- | --------------------------------------------------------------------------------------------------------- |
| 가격 · 용량 | 판매 중인 첫 옵션을 대표로 보여 줍니다. 모두 단종이면 첫 옵션을 보여 줍니다.                              |
| 유수분      | 모든 제품에 값이 없으면 줄째 숨기고, 일부만 없으면 `—`로 표시합니다. 0단계(`없음`)와 구분합니다.          |
| 쓰임새      | 서버가 준 상위 3개를 보여 줍니다.                                                                         |
| 주의 성분   | 든 성분군의 이름을 보여 주고, 하나도 없으면 `없음`을 보여 줍니다.                                         |
| 나만의 필터 | `MATCH`, `NO_MATCH`가 하나도 없으면 줄째 숨깁니다. 로그인 전과 저장한 성분이 없을 때가 여기에 해당합니다. |
| 제품 속성   | 다이소를 뺀 표식을 보여 줍니다. 하나라도 값이 있을 때만 줄을 보여 줍니다.                                 |

## 시안과 다른 점

- **제조업체 줄**: 비교 API와 제품 상세 API 모두 제조사 정보를 주지 않아 넣지 않았습니다.
- **항목 이름**: 시안의 `(6가지 합침)`, `(예시)`는 시안 설명으로 보고 화면 글자에서 뺐습니다.
- **용량 표시**: 시안의 `70ml + 50ml` 같은 묶음 용량은 응답에 없어 대표 옵션의 용량만 보여 줍니다.

## 글자를 키웠을 때

칸 하나에 가격이 들어가는 폭(5.5em)을 지키지 못하면 칸 수를 3개에서 2개, 1개로 줄입니다. 칸이 줄면 칸마다 제품명을 함께 보여 주고, 줄어든 머리는 화면을 많이 가리므로 숨깁니다.
