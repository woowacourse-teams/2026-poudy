## 라우팅과 파라미터

명세는 `/search?mode=product|ingredient`로 적었지만, 이미 색인된 주소와 사이트맵을 지키기 위해 지금 경로를 그대로 둡니다.

| 경로                              | 화면                          | 파라미터                                                                          |
| --------------------------------- | ----------------------------- | --------------------------------------------------------------------------------- |
| `/search`                         | `/search/products`로 보냄     |                                                                                   |
| `/search/products`                | S21 · S21a                    | `keyword`: 입력한 검색어. 상세에 다녀와도 검색어가 남습니다                       |
| `/search/ingredients`             | S22 · S22b · S22c · S31 · S35 | 탐색 조건(`include`, `exclude`, `excludeCode`, `includeGroup`, `excludeGroup` 등) |
| `/search/ingredients?add=include` | S22a · S32 · S32a · S33       | 성분 추가 화면을 성분 탭 위에 덮어 엽니다. `add=exclude`는 S34입니다              |

성분 추가 화면은 같은 경로에 `add`를 붙여 기록을 하나 더 쌓습니다. 그래서 뒤로 가기(내비의 꺾쇠, 기기의 뒤로 버튼)는 고른 것을 버리고 성분 탭으로 돌아갑니다. '추가하기'를 누르면 기록을 하나 되돌린 뒤 그 자리의 주소를 새 조건으로 바꿉니다. 이렇게 해야 성분 탭에서 뒤로 가기를 눌렀을 때 조건을 담기 전 화면이 다시 나오지 않습니다.

## 요구사항

### 공통

- 상단 내비는 `TopBar`(`sub`, '탐색 조건 설정')입니다. 방문 기록이 없으면 꺾쇠가 홈으로 갑니다.
- 검색 모드 탭은 `TabNav`와 `TabNavItem`으로 그리고, 두 경로를 오가는 링크입니다. 조건은 탭을 건너 이어지지 않습니다.
- 하단 내비는 그대로 보입니다. 성분 추가 화면은 하단 내비를 덮습니다.

### 제품명 탭 (S21 · S21a)

| 상태        | 동작                                                                                                                         |
| ----------- | ---------------------------------------------------------------------------------------------------------------------------- |
| 기본        | 회색 검색 입력, 최근 검색(있을 때만), 인기 검색어 패널                                                                       |
| 입력 중     | `Combobox`가 입력과 목록을 잇습니다. 첫 행은 "'검색어' 검색 결과 N개"이고, 그 아래 '제품 바로가기' 묶음에 제품을 보여 줍니다 |
| 불러오는 중 | 결과가 오기 전에는 '검색하는 중…'을 보여 줍니다                                                                              |
| 결과 없음   | `EmptyState`로 검색어를 인용해 알립니다                                                                                      |
| 다음 장     | 목록 끝에 닿으면 다음 장을 불러옵니다                                                                                        |

- Enter는 가리키는 후보가 있으면 그 후보를 고르고, 없으면 결과 목록(`/products?keyword=`)으로 보냅니다. 개수를 세는 중이면 다 센 뒤에 보냅니다.
- 결과 수는 입력이 멈춘 뒤 `Combobox`의 라이브 영역이 한 번 읽어 줍니다(A11Y D06).

### 성분 탭 (S22 · S22c · S31 · S31a)

| 상태         | 동작                                                                                                     |
| ------------ | -------------------------------------------------------------------------------------------------------- |
| 조건 없음    | 두 섹션에 '원하는 성분 검색해서 추가' 같은 큰 버튼을 둡니다. 하단 버튼은 '조건을 골라 주세요'로 막습니다 |
| 조건 있음    | 섹션 제목 옆에 개수와 '+ 추가' 버튼을 두고, 담은 성분은 `Tag`(`item`)로 보여 줍니다. ✕로 뺍니다          |
| 개수 세는 중 | 버튼 숫자는 `RollingNumber`로 굴리고, 세는 동안에는 눌러도 넘어가지 않습니다                             |
| 결과 0개     | '0개 제품 보기'로 막습니다                                                                               |
| 개수 오류    | 숫자 없이 '제품 보기'로 막습니다                                                                         |
| 주소 속 충돌 | 피하는 성분군에 든 성분이 원하는 성분에 함께 있으면 안내 문구를 두고 버튼을 막습니다                     |

- '자주 피하는 성분'은 `ToggleGroup`과 `ToggleChip`으로 켜고 끕니다. 켠 개수는 오른쪽에 'N개 선택'으로 적습니다.
- ⓘ 버튼은 S22b 설명 시트(`BottomSheet`)를 엽니다. 성분군마다 이름, 성분 수, 설명, 예시 성분 세 개와 성분군 설명 링크를 둡니다.
- 조건이 하나라도 있으면 내비 오른쪽에 '초기화'를 둡니다. 성분 조건을 모두 비웁니다.
- S35: 켜려는 자주 피하는 성분에 원하는 성분이 들어 있으면 묻지 않고 켜면서 그 성분을 원하는 성분에서 뺍니다. 탭 아래에 `Notice`로 '리모넨은 ‘향료/알레르기 성분’에 들어 있어 원하는 성분에서 뺐어요.'라고 알리고 [되돌리기]를 둡니다. 규칙은 조건 일치 제품의 성분 시트(S35a, `app/products/SPEC.md`의 '성분 조건 충돌')와 같습니다.

### 성분 추가 화면 (S22a · S32 · S32a · S33 · S34)

| 상태        | 동작                                                                                 |
| ----------- | ------------------------------------------------------------------------------------ |
| 입력 전     | 검색 입력에 포커스를 두고, '추가하기'를 막습니다                                     |
| 결과        | '성분군 N', '성분 N' 묶음으로 나눕니다. 행 오른쪽 원을 눌러 담고, 다시 누르면 뺍니다 |
| 이미 담김   | 담은 성분군에 든 성분은 회색 ✓로 두고 누를 수 없습니다                               |
| 결과 없음   | `EmptyState`로 검색어를 인용해 알립니다                                              |
| 불러오는 중 | '검색하는 중…'을 보여 줍니다                                                         |

- 하단 `BottomActionBar`(`screen-end`)는 새로 담은 개수를 'N개 추가하기'로 적습니다. 담은 것을 빼기만 했다면 '적용하기'입니다.
- S33: 원하는 성분으로 담으려는 성분이 피하는 성분군(자주 피하는 성분 포함)에 들어 있으면 묻지 않고 그 성분군 피하기를 풀고 담습니다. 검색 입력 아래에 `Notice`로 '글라이콜릭애씨드를 담으려고 ‘AHA 성분군’ 피하기를 풀었어요.'라고 알리고 [되돌리기]를 둡니다.
- 피하고 싶은 성분으로 담는 성분군에 원하는 성분이 들어 있으면 성분군을 담으면서 그 성분을 원하는 성분에서 빼고, S35와 같은 문구로 알립니다.
- S34: 성분군을 담을 때 그 성분군에 든 성분을 이미 따로 담았다면 성분군 하나로 묶고 `Toast`로 알립니다.
- 원하는 성분과 피하고 싶은 성분에 같은 성분을 함께 둘 수 없습니다. 다른 쪽에 있던 성분이나 성분군을 담으면 그쪽에서 옮겨 오고, '판테놀을 원하는 성분에서 빼고 여기에 담았어요.'라고 알립니다(S33a).
- 안내 줄은 다음 편집이나 화면을 닫기 전까지 남습니다. [되돌리기]는 정리하기 바로 전 상태로 돌려놓고, 초점은 누른 버튼에 그대로 둡니다.

### 접근성과 반응형

- 탭은 `aria-current="page"`, 자주 피하는 성분은 `aria-pressed`, 추가 화면의 담기 버튼은 `aria-pressed`와 성분 이름이 든 이름('판테놀 담기')을 씁니다.
- 성분 추가 화면은 `role="dialog"`와 `aria-modal`을 두고, 열 때 검색 입력에 포커스를 옮기고 닫을 때 연 버튼으로 돌려줍니다. Tab은 화면 안에서만 돕니다.
- 320 · 360 · 390 폭과 글자 200%에서 가로로 넘치지 않습니다. 긴 성분 이름은 두 줄까지 보이고, 칩은 줄을 바꿔 흐릅니다.

## PostHog 이벤트

지금 화면이 보내는 이벤트입니다. 이름과 속성은 바꾸지 않습니다.

| 이벤트                                               | 언제 보내는지                                                               | 속성                                                                                                                          |
| ---------------------------------------------------- | --------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| `search_started`                                     | 제품명 탭에서 처음 글자를 입력하거나, 성분 탭에서 처음 조건을 바꿀 때 한 번 | `mode`                                                                                                                        |
| `search_used`                                        | 자동완성 결과를 받았을 때(`useSuggestions`)                                 | `mode`, `query`, `query_length`, `result_count`                                                                               |
| `search_suggestion_selected`                         | 제품 자동완성을 고를 때, 성분 추가 화면에서 성분을 새로 담을 때             | `mode`, `query`, `position`, `product_id` 또는 `ingredient_id`                                                                |
| `search_submitted`                                   | 제품 결과 목록으로 갈 때, 성분 탭에서 'N개 제품 보기'를 누를 때             | 제품: `mode`, `query`, `result_count` / 성분: `mode`, `result_count`, `include_count`, `exclude_count`, `exclude_group_count` |

| `recent_search_used`                                 | 최근 검색을 누를 때                                                         | `target_type`, `position`, `product_id` 또는 `query`                                                                          |
| `popular_keyword_used` · `popular_keywords_expanded` | 인기 검색어 패널(`PopularKeywords`)이 보냅니다                              | 그대로                                                                                                                        |
