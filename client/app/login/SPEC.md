| 경로                     | 화면                      | 파일                          |
| ------------------------ | ------------------------- | ----------------------------- |
| `/login`                 | S37                       | `app/login/page.tsx`          |

`/login/callback`은 서버가 소셜 로그인을 마친 뒤 돌려보내는 주소입니다. 받는 파라미터는 바꾸지 않습니다.

| 파라미터   | 값                                                   | 화면                                           |
| ---------- | ---------------------------------------------------- | ---------------------------------------------- |
| `status`   | `WITHDRAWN`, `RESTORE_REQUESTED`, `SIGNUP_REQUIRED`  | S55g, 복구 요청 확인 중, 가입 확인 시트로 이동 |

## 요구사항

### 로그인(S37)

- 기본: 로고, 소개 글, 소셜 로그인 버튼, 약관 안내, [로그인 없이 둘러보기]를 차례로 둡니다.
- 소개 글은 '화장품 선택에 / 나만의 기준을 더하다'이고, '나만의 기준'만 브랜드 강조 색(`brand-strong`)으로 씁니다.
- 소셜 로그인 버튼은 늘 이름이 적힌 넓은 버튼입니다. 높이는 48, 글자는 15입니다.
- 최근 로그인(S37c · S37c-2): 로그인하거나 가입을 마치면 쓴 방법(카카오, Google)을 이 기기에만 남깁니다. 계정 정보는 남기지 않습니다. 기록이 있으면 그 방법의 버튼을 맨 위로 올리고, 나머지는 기본 순서(카카오 → Google)로 둡니다. 맨 위 버튼 위 가운데에 '최근 로그인' 말풍선을 띄우므로 말풍선이 다른 버튼을 덮지 않습니다. 기록이 없으면 S37과 같습니다.
- 말풍선은 화면에서만 보이고(`aria-hidden`) 버튼 이름에 덧붙여 '카카오로 시작하기, 최근 로그인'으로 읽힙니다. 읽는 순서도 화면 순서와 같습니다.
- 가로로 줄인 아이콘 버튼안(S37b · S37b-2)은 채택하지 않아 명세에서 지웠습니다.
- 로그인을 지원하지 않는 예전 앱이면 업데이트 안내가 화면을 덮습니다.
- 로딩·빈 상태·오류: 이 화면은 데이터를 불러오지 않으므로 따로 두지 않습니다. 앱 로그인을 기다리는 동안 버튼에 `aria-busy`를 알립니다.

### 만 14세 이상 확인 시트(S37a)

- 처음 소셜 로그인한 사람에게만 열립니다. 제목과 이유, 체크 행, [동의하고 계속], [로그인 없이 둘러보기]를 둡니다.
- 체크하기 전에는 [동의하고 계속]이 막혀 있습니다. 포커스는 남겨 두고 체크 행을 설명으로 잇습니다(STATE S06 비활성 계약).
- 가입을 요청하는 동안 버튼이 처리 중 상태가 됩니다(STATE S06).
- 가입 시간이 지났거나 다른 방법으로 가입한 이메일이면 토스트로 알립니다. 다시 로그인해야만 가입할 수 있으므로, 그 뒤에 버튼을 누르면 요청하지 않고 같은 안내를 다시 띄웁니다. 그 밖의 실패는 토스트로 알리고 다시 시도할 수 있게 둡니다.
- Esc, 딤 누르기, 끌어내리기로 닫으면 `/login`으로 돌아갑니다. 서버에 맡겨 둔 계정은 10분 뒤 사라집니다.

### 가입 정보 입력(S38 · S38a · S38b)

- 성별, 나이대, 피부 타입, 민감한지를 따로 묻습니다. 아는 것만 골라도 시작할 수 있고, 고른 선택지를 다시 누르면 선택이 풀립니다.
- 하나도 고르지 않았으면 하단 버튼 글자가 '하나 이상 골라 주세요'로 바뀌고 막힙니다(S38a).
- 저장하는 동안 버튼이 처리 중 상태가 됩니다. 저장하지 못하면 토스트로 알리고 다시 누를 수 있게 둡니다.
- 로그인이 풀렸으면 `/login`으로 보내고, 관리자 세션이면 관리자 로그아웃 안내를 보여 줍니다.
- 머리에는 제목 '나에 대해 알려 주세요'와 설명 한 줄만 둡니다. 명세에서 자물쇠 안내 줄을 껐으므로 화면에도 두지 않습니다.
- '내 피부 타입을 잘 모르겠어요' 링크는 피부 타입 테스트를 열기 전까지 두지 않습니다.

### 탈퇴 계정 되살리기(S55g)

- 탈퇴한 날과 되살릴 수 있는 마지막 날, 계정 이메일, 되살리면 돌아오는 것을 보여 줍니다. 계정 정보를 불러오지 못하면 날짜 대신 복구를 요청하라는 문구를 보여 줍니다.
- [계정 되살리기]를 누르면 복구를 요청하고, 요청하는 동안 버튼이 처리 중 상태가 됩니다. 요청하면 '복구를 요청했어요' 화면으로 바뀝니다.
- 요청하지 못하면 토스트로 알립니다. 임시 세션이라 다시 시도하려면 다시 로그인해야 하므로, 그 뒤에 버튼을 누르면 요청하지 않고 같은 안내를 다시 띄웁니다. 토스트는 사라지기 때문에 버튼을 막으면 이유를 다시 읽을 곳이 없어집니다(FEEDBACK F04).

### 다른 방법으로 가입한 이메일(S55h · S55i)

- 가입한 방법과 이메일을 보여 주고, 그 방법으로 바로 로그인하는 브랜드 버튼과 [다른 방법으로 로그인]을 둡니다.
- 계정 정보를 불러오지 못하면 이메일 카드 없이 주소의 `provider`로 안내합니다.

### 접근성

- 상단 내비의 제목은 `p`로 내리고 본문 제목을 `h1`로 둡니다.
- 뒤로가기는 사이트 안에서 온 기록이 있으면 '이전 화면'으로 돌아가고, 없으면 '홈으로' 링크가 됩니다.
- 시트는 `role="dialog"`와 `aria-modal`을 쓰고 제목과 이유를 이름과 설명으로 잇습니다. 닫으면 연 요소로 포커스를 돌려줍니다(A11Y D02).
- 막힌 버튼은 `aria-disabled`로 막아 포커스가 남게 합니다.
- 토스트는 polite 라이브 영역으로 알립니다(A11Y D06).

### 반응형

- 320·360·390 폭에서 가로로 넘치지 않고, 글자 200%에서도 잘리지 않아야 합니다.
- 하단 행동 영역은 스크롤해도 화면 끝에 남고, 본문만 스크롤합니다.

## 바꿀 부품

| 지금                                        | 바꿀 디자인 시스템 부품                                 | 화면            |
| ------------------------------------------- | ------------------------------------------------------- | --------------- |
| `components/ui/BottomSheet`                 | `BottomSheet` + `BottomSheetHeader` · `BottomSheetBody` | S37a            |
| `components/ui/TopBar`                      | `TopBar`(`sub`)                                         | S55g~S55i       |
| 화면 끝에 붙인 하단 영역(`sticky bottom-0`) | `BottomActionBar`(`screen-end`)                         | S38             |
| 버튼 위 실패 문구(`role="alert"`)           | `useToast`(앱 레이아웃에 `ToastProvider`)               | S37a, S38, S55g |
| 직접 짠 골격(`main` · `sticky`)             | `Screen` + `ScreenBody`                                 | S38, S55g~S55i  |

S55g와 S55h·S55i의 하단 영역(명세 '하단 행동 영역 · 두 버튼')은 큰 버튼 아래에 글자 버튼이 하나 더 있고, S55h·S55i의 큰 버튼은 브랜드 색 로그인 버튼입니다. `BottomActionBar`는 큰 버튼 하나만 받으므로, 이 세 화면의 하단 영역은 `BottomActionBar`와 같은 틀로 화면 전용 컴포넌트(`AccountActionArea`)에 둡니다. 만 14세 확인 시트의 하단도 같은 까닭으로 `BottomSheetFooter` 대신 시트 안에서 짭니다.

토스트는 `#overlay-root`에 그려지므로 화면의 CSS 변수를 물려받지 못합니다. 하단 영역이 있는 화면은 표식(`data-toast-offset`)을 두고, `app/globals.css`가 `:root:has()`로 `--toast-offset`을 정해 토스트를 하단 영역 바로 위에 띄웁니다.
