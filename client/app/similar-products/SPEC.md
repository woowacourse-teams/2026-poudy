# 유사템 찾기

Figma: poudy design → v3 - 선반 추가 후 고도화 → image 6 (`1759:563`).
기존 디자인 시트의 Screen·TopBar·ToggleChip·EmptyState·ErrorState·Skeleton과 제품 이미지 규칙을 사용한다.

## 결과

- 경로: `/similar-products/[productId]?partId=구성품ID&sort=UNIT_PRICE_ASC|SIMILARITY`.
- 정렬을 생략하면 저렴한 순이다. 구성품을 생략하면 서버의 첫 구성품을 기준으로 한다.
- 기준 제품 카드: 이미지, 브랜드, 제품명, 대표 용량·가격·단가. 여러 구성품은 비교 대상 이름을 표시한다.
- 성분이 비슷한 상위 10개를 서버 정렬 그대로 표시한다. 제목은 실제 표시 개수이며 더보기는 없다.
- 후보 행: 이미지, 브랜드, 제품명, 용량·가격·서버 단가·가격 차이. 비교 불가는 비율을 쓰지 않는다.
- 저렴한 가격 차이는 success-text, 동일·비쌈·비교 불가는 text-secondary다. 성분 유사도 등급은 표시하지 않는다.
- 개인별 판정 정보 없이 ‘주의 없음’을 표시하지 않는다. 기존 상세의 최대 3개 미리보기는 유지한다.
- 로딩은 스켈레톤, 0개는 빈 상태, 유사템 조회 실패는 기준 제품 아래 재시도, 제품 조회 실패는 화면 오류로 표시한다.
- 없는 제품·구성품과 잘못된 ID는 404다. 미계산·후보 없음은 같은 빈 상태로 표시한다.
- 정렬은 URL을 replace하고 스크롤을 유지한다. 대상 구성품 상세는 partHref로 연결하며 문서 스크롤과 Next.js의 뒤로 가기 복원을 사용한다.
- 직접 진입한 결과의 뒤로가기는 `/similar-products`, 내부 진입은 이전 방문 기록으로 돌아간다.
- 로그인 없이 접근한다. 하단 내비게이션과 홈 진입점은 추가하지 않는다.

## 검색·선반 선택

- 시작 경로: `/similar-products?q=검색어`. 검색어를 주소에 남기고, 별도 검색 결과 페이지는 열지 않는다.
- 입력 아래 이미지·브랜드·제품명이 있는 후보를 최대 5개 표시한다. 기존 suggestions API에 page=1·size=5를 요청한다.
- 입력이 300ms 멈추면 조회한다. 한글 조합 중에는 기다리고, 이전 요청의 응답은 현재 검색 결과를 덮어쓰지 않는다.
- 기존 Combobox·SearchField를 사용한다. 방향키로 후보를 가리키고 Enter로 선택하며 Esc로 닫는다. 후보를 가리키지 않은 Enter는 이동하지 않는다.
- 지우기, 검색 중, 결과 없음, 실패·재시도를 지원한다. 최근 검색 목록은 메모리에 잠시 남겨 뒤로 가기에 복원한다.
- 선택한 제품은 `/similar-products/[productId]?sort=UNIT_PRICE_ASC`로 이동한다. 검색·선반 모두 첫 구성품을 서버에서 선택한다.
- 내 선반 미리보기는 최근 등록 제품 10개를 가로로 보여 주고 ‘전체’는 기존 BottomSheet에서 선반 전체 목록을 연다.
- 선반은 기존 선반 목록 API만 요청한다. 로딩·로그인 전·빈 선반·조회 실패·재시도를 구분하며 검색은 계속 사용할 수 있다.
- 로그인 전에는 선반 영역에서 로그인하기를 제공한다. 기존 rememberLoginReturn으로 검색어를 포함한 현재 주소를 기억한다.
- 시트를 닫으면 전체 버튼으로 포커스를 돌리고, 제품을 선택하면 시트를 닫고 결과 화면으로 이동한다.
- 시작·결과·선반 선택 시트에 하단 내비게이션이 없다. 홈 진입점과 ‘요즘 많이 찾는 저렴이’는 추가하지 않는다.
