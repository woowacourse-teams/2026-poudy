## 결과

- 경로: `/similar-products/[productId]?partId=구성품ID&sort=UNIT_PRICE_ASC|SIMILARITY`.
- 정렬을 생략하면 저렴한 순이다. 구성품을 생략하면 서버의 첫 구성품을 기준으로 한다.
- 기준 제품 카드: 이미지, 브랜드, 제품명, 대표 용량·가격·단가. 여러 구성품은 비교 대상 이름을 표시한다.
- 성분이 비슷한 상위 10개를 서버 정렬 그대로 표시한다. 제목은 실제 표시 개수이며 더보기는 없다.
- 후보 행: 이미지, 브랜드, 제품명, 용량·가격·서버 단가·가격 차이. 비교 불가는 비율을 쓰지 않는다.
- 저렴한 가격 차이는 success-text, 동일·비쌈·비교 불가는 text-secondary다. 성분 유사도 등급은 표시하지 않는다.
- 개인별 판정 정보 없이 ‘주의 없음’을 표시하지 않는다. 기존 상세의 최대 3개 미리보기는 유지하고, 그 섹션 머리의 ‘더보기’로 이 결과에 들어온다.
- 로딩은 스켈레톤, 0개는 빈 상태, 유사템 조회 실패는 기준 제품 아래 재시도, 제품 조회 실패는 화면 오류로 표시한다.
- 없는 제품·구성품과 잘못된 ID는 404다. 미계산·후보 없음은 같은 빈 상태로 표시한다.
- 정렬은 URL을 replace하고 스크롤을 유지한다. 대상 구성품 상세는 partHref로 연결하며 문서 스크롤과 Next.js의 뒤로 가기 복원을 사용한다.
- 직접 진입한 결과의 뒤로가기는 `/similar-products`, 내부 진입은 이전 방문 기록으로 돌아간다.
- 로그인 없이 접근한다. 하단 내비게이션은 추가하지 않는다.

## 검색·파우치 선택

- 시작 경로: `/similar-products?q=검색어`. 검색어를 주소에 남기고, 별도 검색 결과 페이지는 열지 않는다.
- 입력 아래 이미지·브랜드·제품명이 있는 후보를 최대 5개 표시한다. 기존 suggestions API에 page=1·size=5를 요청한다.
- 입력이 300ms 멈추면 조회한다. 한글 조합 중에는 기다리고, 이전 요청의 응답은 현재 검색 결과를 덮어쓰지 않는다.
- 입력값은 기존 제품 검색 화면처럼 React 상태로 유지한다. 한글 조합 중에는 주소를 바꾸지 않고, 입력이 멈춘 완성 검색어만 URL에 저장한다.
- 조회 지연·이전 요청 취소·실패·재시도는 공용 `useSuggestions`를 사용한다. 유사템 전용 코드는 5개 조회와 목록 복원만 맡는다.
- 기존 Combobox·SearchField를 사용한다. 방향키로 후보를 가리키고 Enter로 선택하며 Esc로 닫는다. 후보를 가리키지 않은 Enter는 이동하지 않는다.
- 지우기, 검색 중, 결과 없음, 실패·재시도를 지원한다. 최근 검색 목록은 메모리에 잠시 남겨 뒤로 가기에 복원한다.
- 선택한 제품은 `/similar-products/[productId]?sort=UNIT_PRICE_ASC`로 이동한다. 검색·파우치 모두 첫 구성품을 서버에서 선택한다.
- 내 파우치 미리보기는 최근 등록 제품 10개를 가로로 보여 주고 ‘전체’는 기존 BottomSheet에서 파우치 전체 목록을 연다.
- 파우치는 기존 파우치 목록 API만 요청한다. 로딩·로그인 전·빈 파우치·조회 실패·재시도를 구분하며 검색은 계속 사용할 수 있다.
- 로그인 전에는 파우치 영역에서 로그인하기를 제공한다. 기존 rememberLoginReturn으로 검색어를 포함한 현재 주소를 기억한다.
- 시트를 닫으면 전체 버튼으로 포커스를 돌리고, 제품을 선택하면 시트를 닫고 결과 화면으로 이동한다.
- 시작·결과·파우치 선택 시트에 하단 내비게이션이 없다. 홈 바로가기의 유사템찾기가 시작 화면으로 연결된다.

## 요즘 많이 찾는 저렴이

- 내 파우치 영역 아래에 로그인과 관계없이 표시한다. 파우치의 로그인 전·빈 결과·조회 실패가 이 목록을 숨기지 않는다.
- 모든 환경에서 `mocks/popular-dupes.ts`의 같은 고정 조합 3개를 표시한다. 제품명·이미지·단가·절감률은 공통으로 관리한다. `popularDupesForEnvironment`는 실제 DB에서 다른 제품·구성품 ID만 매핑하며, `NEXT_PUBLIC_ENVIRONMENT=staging` 외에는 운영 ID를 사용한다. 기존 제품 이미지·목록 행 규칙과 디자인 토큰을 따른다.
- 기준 제품과 대체 제품의 이미지, 기준 제품명, 대체 제품 브랜드·제품명, 단위 가격 변화와 절약률을 보여 준다.
- 소개 문구와 섹션 보조 설명 없이 제목과 목록을 표시한다. 고정 목록이며, 실시간 순위는 아니다.
- 행을 누르면 기준 제품·구성품의 유사템 결과로 이동한다. 표시할 조합이 없으면 검색을 안내하는 빈 상태를 보여 준다.
- 페이지에서 데이터를 받아 카드에 넘긴다. #1037의 후속 서버 작업에서 기존 대체 제품의 조회수 기준 공개 API로 교체한다.
- 공통 목록은 완료된 최근 7일(2026-11-05~11-11)의 staging 대체 제품 조회수 내림차순으로 3개를 고른다. 조회수가 같으면 대체 제품 ID 순이다. 같은 대체 제품의 여러 관계 중 기준 제품 조회수, 유사도 내림차순, 기준 제품·구성품 ID 순으로 하나를 선택한다. 자동 갱신 계약은 후속 서버 작업에서 정한다.
- 각 환경 API의 실제 유사제품 목록에서 같은 카테고리·단위의 판매 중인 제품을 고른다. 총가격과 단위 가격이 모두 낮은 조합을 사용하고 대체 제품은 중복하지 않는다.
- 결과의 단가·가격 차이·정렬에는 #1038 백엔드 배포가 필요하다. 제품이 있어도 해당 구성품의 유사도가 계산되지 않았으면 결과는 빈 상태다.
