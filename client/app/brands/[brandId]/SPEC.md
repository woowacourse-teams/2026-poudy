## 화면 구성

위에서 아래로 다음 순서로 쌓습니다.

1. 탐색 앱바: `TopBar variant="explore" align="center"`를 씁니다. 높이는 56입니다. 본문에 대표 제목이 있으므로 바의 제목은 `p`로 내립니다. 바 아래 선은 필터 칩 줄이 맡으므로 바에서는 끕니다.
   - 맨 위에서는 제목이 '브랜드관'입니다. 브랜드명은 히어로가 크게 보여 주므로 바에서 반복하지 않습니다.
   - 히어로의 브랜드명이 바 아래로 완전히 가려지면 제목이 로고 24와 브랜드명으로 바뀝니다(S30-1). 다시 올라가 브랜드명이 보이면 '브랜드관'으로 돌아갑니다.
   - 두 제목을 한 칸에 겹쳐 두고 불투명도만 바꿉니다(`--duration-fast` 150ms). 움직임 줄이기 설정이면 바로 바뀝니다. 바 높이는 바뀌지 않습니다.
   - 가려졌는지는 브랜드명 아래 끝에 겹쳐 둔 표식을 IntersectionObserver(`usePassedTopBoundary`)로 봅니다. 스크롤마다 위치를 재지 않습니다.
2. 브랜드 히어로(명세 `라운드랩 브랜드 히어로`): 본문 위 12, 좌우 거터 16, 아래 칩 줄까지 12를 둡니다. 회색 면(`bg-surface`, `rounded-2xl`, 안쪽 위아래 20·좌우 16) 가운데에 원형 로고 56(바탕색 면, `info-soft` 1px 테두리), 브랜드명, 영문명을 세로로 둡니다. 로고와 이름 사이는 12, 이름과 영문명 사이는 4입니다. 브랜드명은 `text-hero`(24/700) `h1`, 영문명은 `text-caption`(12/500) `text-secondary`입니다. 제품 수는 바로 아래 목록 머리('총 N개')와 겹쳐 두지 않습니다.
3. 제품 목록: 공유 부품 `ProductList`(#736)를 둡니다. 필터 칩 줄은 앱바 바로 아래(56)에 붙습니다.

옛 화면에서 머리가 지나간 뒤 나타나던 축약형(`SummaryHeader`의 `BrandCompact`)은 두지 않습니다. 그 역할은 바 제목이 맡습니다.

## 상태별 동작

| 상태      | 동작                                                                                                                                                                               |
| --------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 기본      | 앱바와 히어로는 브랜드 상세를 받은 뒤 서버가 그립니다. 히어로에 제품 수가 없어져 따로 스트리밍하지 않습니다. 제품 목록만 스트리밍합니다                                            |
| 로딩      | 목록 자리에 `ProductListSkeleton`을 둡니다                                                                                                                                         |
| 빈 상태   | 사용자가 건 조건이 있으면 '조건에 맞는 제품이 없어요'와 [조건 모두 지우기]를 보여 줍니다. 조건이 없으면 '아직 이 브랜드에 등록된 제품이 없어요'와 [브랜드 전체 보기]를 보여 줍니다 |
| 없는 주소 | 숫자가 아니거나 서버가 404를 돌려주면 셸을 보내기 전에 `notFound()`를 부르고 S51f를 그립니다                                                                                       |
| 오류      | 목록 조회가 실패하면 공유 부품이 다시 요청합니다. 브랜드 상세 조회가 다른 이유로 실패하면 `app/error.tsx`가 그립니다                                                               |

## 접근성

- 머리의 브랜드 이름이 문서의 대표 제목(`h1`)입니다.
- 로고는 옆이나 아래에 이름이 있으므로 `alt=""`로 둡니다(A11Y D05, IMAGE).
- 바 제목은 두 제목 가운데 보이는 쪽만 읽습니다. 숨은 쪽은 `aria-hidden`입니다. 스크롤 뒤의 접근 가능한 이름은 브랜드명 하나입니다.
- 뒤로가기의 이름은 `이전 화면`입니다. 이 사이트 안에서 쌓인 방문 기록이 없으면 `브랜드 전체`라는 이름의 링크가 되어 `/brands`로 이동합니다.

## 반응형

- 320·360·390 폭에서 가로로 넘치지 않습니다. 긴 브랜드 이름은 바에서는 한 줄로 줄이고, 히어로에서는 줄을 바꿉니다.
- 글자를 200%로 키워도 로고는 크기를 유지하고 히어로가 높이를 늘립니다.
- 히어로 로고(56)와 바 로고(24)는 같은 이미지 주소를 쓰고 CSS 크기만 다릅니다. 그림을 한 번만 받습니다.
