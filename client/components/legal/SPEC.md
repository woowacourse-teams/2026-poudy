# 명세 밖 화면 디자인 시스템 적용 계획

- 이슈: [#742 \[FEAT\] 명세 밖 화면에 디자인 시스템을 적용한다](https://github.com/woowacourse-teams/2026-poudy/issues/742) (상위 #722 · 단계 2-12)
- 브랜치: `feat/742-off-spec-ds`
- 종류: 옮기기. 화면 구성은 그대로 두고, 직접 쓴 값을 토큰으로, 옛 부품을 디자인 시스템 부품으로 바꿉니다.

이 문서는 약관 화면의 부품이 모인 이 폴더에 두지만, 아래 네 경로를 함께 다룹니다.

## 명세 판단

명세 프레임이 없어서 비슷한 명세 화면과 공통 보드를 기준으로 정한 곳입니다.

- 약관 본문은 법률 문서이므로 문구를 바꾸지 않습니다. 이슈가 정한 사항입니다.
- 약관 본문 글자는 지금처럼 13(`text-body-sm`)으로 둡니다. 행간은 24px라서 토큰에 없으므로, 긴 읽기 문단의 행간인 `leading-relaxed`(1.6)로 옮깁니다(TYPO T02). 13은 크기 단계에 있는 값이라 14로 올리지 않았습니다.
- 문서 제목 18 → `text-block`, 조문 제목 15 → `text-title`, 시행일 같은 메타 글자 12 → `text-caption`으로 옮깁니다(TYPO T02).
- 본문 거터는 `px-4` 대신 `px-gutter`를 씁니다. 360 미만에서는 12가 됩니다(LAYOUT L02). 본문 끝 40은 '하단 고정 영역 없이 끝나는 긴 상세'의 끝 여백 4xl과 같아서 그대로 둡니다(LAYOUT L04).
- 처리방침 표를 세운 카드는 반경을 `rounded-lg`(12)로 두고, 항목 이름 칸 68px은 `w-17`로 씁니다. 같은 값이라 모양은 바뀌지 않습니다.
- 이용약관의 시행 예정 약관은 `<details>` 대신 디자인 시스템의 `Disclosure`로 펼칩니다. 펼치는 줄은 APP · 질문 행의 글자(15 · 600)와 꺾쇠(20)를 따르고, 지금의 테두리 상자는 그대로 둡니다. 접힌 동안에도 내용은 `hidden`으로 문서에 남아 검색엔진과 페이지 내 찾기가 읽을 수 있습니다. `DisclosureTrigger`는 넘겨받은 버튼을 복제하므로, 펼치는 상자는 client 컴포넌트 `ScheduledTermsDisclosure`로 두고 약관 본문은 서버에서 그려 넘깁니다.
- 앱으로 이동 화면의 안내 글은 빈 상태 제목과 같은 `text-section` 700으로 옮깁니다(FEEDBACK F03 견본). 스토어 링크는 테두리 버튼 대신 본문 안 보조 버튼(Secondary, 높이 48)의 모양을 씁니다. BTN · Outline(32)은 목록 행 오른쪽의 가벼운 행동에만 쓰기 때문입니다.
- 디자인 시스템 `Button`은 링크로 그릴 수 없습니다. 그래서 스토어 링크는 `<a>`에 `usePressable`과 Secondary 버튼과 같은 클래스를 붙여 그립니다. 패키지에 링크 버튼이 생기면 바꿉니다.
- 상단 내비는 디자인 시스템 `TopBar`(`sub`)를 씁니다. 방문 기록이 없으면 '홈으로' 링크로 바꾸는 동작은 옛 `TopBar`와 같게 유지해야 합니다. 이 동작은 공용 훅 `components/navigation/useSubScreenBack`이 맡고, 서버 컴포넌트 화면은 훅을 부를 수 없어 이를 감싼 client 컴포넌트 `SubTopBar`를 씁니다.
- 같은 뒤로가기를 각자 들고 있던 탐색 조건의 `SearchTopBar`, 로그인의 `useSubScreenBack`, 디렉터리의 `DirectoryTopBar`도 이 훅으로 모읍니다. `SearchTopBar`는 제목과 '초기화' 버튼 말고는 `SubTopBar`와 같아서 지우고, `DirectoryTopBar`는 탐색 앱바(`explore`) 모양 때문에 남기되 기록이 없을 때 갈 상위 디렉터리를 훅에 넘깁니다.
- 공유한 제품 찾기의 빈 상태는 다른 빈 상태 화면(위시리스트)처럼 남은 자리의 가운데에 둡니다. 지금까지는 본문 위쪽에 붙어 있었습니다. 빈 상태의 내용은 지금처럼 아이콘과 문구만 둡니다. 검색 화면으로 가는 행동을 더하면 F03에 더 맞지만, 옮기기 범위를 넘어서므로 제안으로만 남깁니다.

## 요구사항

### 개인정보 처리방침 · 이용약관

| 상태    | 동작                                                                                                          |
| ------- | ------------------------------------------------------------------------------------------------------------- |
| 기본    | 서버에서 미리 그립니다. 상단 내비 → 문서 제목과 시행일 → 조문 순서이고, 문서 전체가 스크롤합니다(L04 문서형). |
| 펼침    | 이용약관의 시행 예정 약관 줄을 누르면 그 자리에서 펼치고 접습니다. 처음에는 접혀 있습니다.                    |
| 로딩    | 없습니다. 정적 문서입니다.                                                                                    |
| 빈 상태 | 없습니다.                                                                                                     |
| 오류    | 없습니다.                                                                                                     |

### 앱으로 이동

| 상태 | 동작                                                                                                                                              |
| ---- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| 기본 | 붙은 뒤에 환경을 보고 앱이나 스토어로 바로 넘깁니다. 넘기기 전이나 넘기기가 막힌 경우를 위해 안내 글과 'Play 스토어에서 받기' 링크를 보여 줍니다. |
| 오류 | 넘기기가 막히면 같은 화면이 남고, 링크로 직접 이동할 수 있습니다.                                                                                 |

### 공유한 제품 찾기

| 상태    | 동작                                                                                                |
| ------- | --------------------------------------------------------------------------------------------------- |
| 기본    | 공유 텍스트로 제품을 찾으면 상세로, 검색어만 남으면 목록으로 곧장 보내고 이 화면은 그리지 않습니다. |
| 빈 상태 | 찾지 못했거나 서버에 닿지 못하면 '공유한 내용에서 제품을 찾지 못했어요' 빈 상태를 보여 줍니다(F03). |

### 접근성

- 상단 내비의 뒤로가기는 이름이 '이전 화면'이고, 방문 기록이 없으면 '홈으로' 링크가 됩니다(A11Y D05).
- 펼치기 줄은 `button`이고 `aria-expanded`와 `aria-controls`를 가집니다(A11Y D04).
- 포커스 링은 디자인 시스템의 공통 링을 씁니다(STATE S06). 본문 안 링크는 밑줄로 링크임을 알립니다.
- 320·360·390 폭에서 가로로 넘치지 않고, 글자 200%에서도 잘리지 않습니다(A11Y D08·D09).

### 움직임

- 펼치기 꺾쇠만 180° 돌고(150ms), 내용은 바로 나타나고 사라집니다(MOTION '펼치기 · 접기'). `Disclosure`가 맡습니다.
- 버튼과 행의 눌림은 `fb-*`와 `press-scale`이 맡습니다(STATE S07).

| 경로              | 파라미터 | 담는 값                                   | 없을 때                   |
| ----------------- | -------- | ----------------------------------------- | ------------------------- |
| `/open-app`       | `source` | QR 진입 경로(`qr_scan`·`qr_click` 등)     | `unknown`으로 기록합니다. |
| `/open-app`       | `store`  | `google_play`면 설치 진입을 기록하지 않음 | 설치 진입을 기록합니다.   |
| `/share/redirect` | `text`   | 앱이 공유받은 텍스트                      | 빈 상태를 보여 줍니다.    |

이 이슈에서 라우팅과 파라미터는 바꾸지 않습니다.

## 바꿀 부품

| 지금                                                                                     | 바꾼 뒤                                                                   |
| ---------------------------------------------------------------------------------------- | ------------------------------------------------------------------------- |
| `components/ui/TopBar`(옛 상단 내비)                                                     | `components/navigation/SubTopBar` → `@poudy/design-system/top-bar`(`sub`) |
| `<details>`·`<summary>`                                                                  | `@poudy/design-system/disclosure`                                         |
| `components/ui/icons/Icon`                                                               | `@poudy/design-system/icon`                                               |
| 스토어 링크의 직접 쓴 테두리 버튼                                                        | `usePressable` + Secondary 버튼 클래스                                    |
| `text-[12px]`·`text-[13px]`·`text-[15px]`·`text-[18px]`, `leading-6`, `w-[68px]`, `mt-*` | 역할 토큰, `leading-relaxed`, `w-17`, `gap`                               |

옛 `components/ui/TopBar`는 다른 화면이 아직 써서 지우지 않습니다(#743). `FooterLink`는 홈과 서비스 소개의 푸터가 쓰므로 이 이슈에서 고치지 않습니다.

대상 경로(`app/privacy`, `app/terms`, `app/share`, `app/open-app`, `components/legal`, 그리고 이 이슈가 고친 `components/navigation`의 두 파일)는 `eslint.config.mjs`의 `tokenStrictFiles`에 넣어 디자인 토큰 린트를 오류로 올립니다.
