# FilterChip

누르면 조건 시트를 여는 필터 칩입니다. 값이 적용되면 이름 자리에 값을 쓰고 검은 면이 됩니다. 칩 줄 맨 앞에는 조건을 한 번에 비우는 `FilterResetChip`을 둡니다. 같은 칩 줄에서 시트 없이 바로 켜고 끄는 내 설정('나만의 필터')은 `FilterToggleChip`입니다.

## 언제 쓰나

- 제품 목록 위 칩 줄에서 성분, 피부 타입, 브랜드 같은 조건 시트를 열 때 씁니다.
- 적용된 값은 이름 자리에 바로 씁니다. 성분은 '성분 N'(개수), 브랜드 여러 개는 '닥터지 외 2개', 유수분은 '수분감 보통~높음'처럼 씁니다.
- `FilterResetChip`은 늘 칩 줄 맨 앞에 둡니다. 비울 조건이 없으면 숨기지 않고 비활성으로 막습니다. 숨기면 조건을 걸고 지울 때마다 칩이 버튼 폭만큼 밀리기 때문입니다.
- `FilterToggleChip`은 초기화 칩 바로 뒤에 둡니다. 시트를 여는 칩과 구별되게 뒤 꺾쇠 대신 앞에 아이콘(나만의 필터는 user-check 14)을 둡니다. 로그인 여부와 상관없이 보여 줍니다. 칩은 누르면 `onPress`만 부르고, 바로 켤지 확인 시트를 먼저 띄울지는 화면이 정합니다(나만의 필터는 로그인 전이면 로그인 안내, 비어 있으면 선반 안내 시트).

## 쓰지 않는 경우

- 켜고 끄는 조건(빠른 필터)은 ToggleChip을 씁니다.
- 적용된 조건을 읽기만 하는 줄은 Tag(summary)를 씁니다.
