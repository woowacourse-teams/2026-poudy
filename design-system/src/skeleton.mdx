# Skeleton

첫 로딩 동안 실제 내용이 올 자리를 같은 크기의 회색 면(ui-surface)으로 채웁니다. 내용이 와도 자리가 바뀌지 않게 실제와 같은 크기로 둡니다.

<Unstyled>
  <SpecSources boards={["FEEDBACK F02", "S50a", "MOTION M02"]} issues={["#728"]} source="src/skeleton.tsx" />
</Unstyled>

## 언제 쓰나

- 화면을 처음 불러오는 동안 목록 행, 카드 같은 자리를 그대로 흉내 낼 때 씁니다. 모양은 `shape`(줄 `line`, 상자 `box`)로 고릅니다.
- 늦게 켜고 잠깐 유지하는 것은 `useDelayedFlag`로 정합니다. 300ms 안에 끝나는 요청은 아무것도 보이지 않고, 한 번 켜면 적어도 500ms 둡니다. 10초가 넘으면 `useSlowFlag`로 '시간이 조금 걸리고 있어요'와 [다시 시도]를 함께 보입니다.

## 쓰지 않는 경우

- 다음 장을 불러오는 중에는 LoadMore를 씁니다.
- 버튼을 누른 뒤의 처리 중은 Button의 `busy`를 씁니다.
