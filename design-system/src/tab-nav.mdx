# TabNav

다른 화면으로 가는 링크 탭입니다. `TabNav` 안에 `TabNavItem`을 두고, 각 항목에 client의 `Link`를 넘깁니다. 고른 탭에는 `aria-current="page"`가 붙습니다.

## 언제 쓰나

- 검색 모드 탭(`?mode=`)과 카테고리·브랜드 전환(`/categories` ↔ `/brands`)에 씁니다.
- 높이 44이고 탭이 폭을 똑같이 나눕니다. 고른 탭은 15/700 + 2px 밑줄, 나머지는 15/500 secondary입니다.
- `transitionName`을 주면 화면을 옮길 때 밑줄이 이전 탭에서 새 탭으로 미끄러집니다. 두 화면이 같은 이름을 써야 이어집니다.

## 쓰지 않는 경우

- 같은 화면의 패널만 바꾸는 탭은 Tabs를 씁니다.
