# Tabs

같은 화면에서 아래 패널만 바꾸는 탭입니다. `Tabs` 안에 `TabList`·`Tab`·`TabPanel`을 두고, 글자만 있는 탭 이름은 `TabLabel`로 감쌉니다. 다른 화면으로 가는 탭은 TabNav를 씁니다.

## 언제 쓰나

- **underline · fixed:** 탭이 폭을 똑같이 나누는 밑줄 탭입니다(성분 · 사용 후기 · 유사 제품).
- **underline · scroll:** 내용 폭대로 두고 가로로 미는 밑줄 탭입니다(구성품 탭). 오른쪽 끝에 고정 칸(`end`, 예: [전체])을 둘 수 있습니다.
- **rail:** 디렉터리의 세로 레일입니다. 회색 레일 안에서 고른 칸만 흰 바탕이라 오른쪽 흰 패널과 이어집니다.
- 고른 탭을 주소에 남겨야 하면 `asChild`로 client의 `Link`를 넘깁니다(replace, prefetch).
- `transitionName`을 주면 고른 탭이 바뀔 때 밑줄이 이전 탭에서 새 탭으로 미끄러집니다. 고르는 변경은 `startTransition`으로 감쌉니다.

## 쓰지 않는 경우

- 다른 화면으로 가는 탭(검색 모드, 카테고리·브랜드 전환)은 TabNav를 씁니다.
- rail 에는 밑줄이나 막대를 두지 않고, 분홍 면(brand-soft)도 쓰지 않습니다. 면으로만 선택을 표시합니다.
