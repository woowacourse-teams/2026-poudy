# ErrorState

데이터를 불러오지 못했을 때의 모양입니다. 모양만 맡고, 언제 보여 줄지는 화면이 정합니다.

<Unstyled>
  <SpecSources boards={["FEEDBACK F06", "S51 · S51a"]} issues={["#728"]} source="src/error-state.tsx" />
</Unstyled>

## 언제 쓰나

- **screen:** 화면 전체를 그리지 못했을 때입니다. 화면 전체 오류는 `app/error.tsx`, 없는 주소는 `not-found.tsx`가 이 모양으로 그립니다. 문의할 때 쓸 오류 코드(`code`)를 함께 둘 수 있습니다.
- **section:** 화면의 한 섹션만 불러오지 못했을 때입니다. 한 줄 문구와 [다시 시도]입니다.

## 쓰지 않는 경우

- 결과가 0개인 것은 오류가 아닙니다. EmptyState를 씁니다.
- 입력 칸의 검사 오류는 입력 부품이 칸 아래에 보여 줍니다.
