# Select

선택 입력입니다. 한 줄 입력과 같은 칸에 오른쪽 ⌄가 붙고, 누르면 선택 시트가 열립니다. 부품은 칸만 맡고, 시트는 화면이 BottomSheet로 엽니다.

<Unstyled>
  <SpecSources boards={["APP · 입력 · 선택", "STATE S06", "A11Y D02"]} issues={["#726"]} source="src/select.tsx" />
</Unstyled>

## 언제 쓰나

- 폼에서 목록 가운데 하나를 고를 때(브랜드, 카테고리) 씁니다. 고르는 목록은 시트 안의 RadioGroup으로 그립니다.
- 시트가 열려 있는 동안 `expanded`를 넘기면 칸이 '입력 중' 모양이 됩니다.

## 쓰지 않는 경우

- 선택지가 몇 개뿐이고 화면에 바로 늘어놓을 수 있으면 RadioGroup(choice · card)을 씁니다.
- 목록 결과 헤더의 정렬처럼 가벼운 자리에서는 Dropdown을 씁니다.
