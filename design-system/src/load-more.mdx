# LoadMore

목록의 앞뒤 장을 불러오는 자리입니다. 다음 장은 스크롤로 저절로 부르고, 실패 뒤 다시 시도와 이전 장은 버튼으로만 부릅니다. 저절로 API를 다시 부르지 않습니다.

## 언제 쓰나

- **next:** 목록 끝에 둡니다. 끝에 닿으면 다음 20개를 저절로 불러오고, 불러오는 동안 스피너와 '지금 개수 / 전체 개수 · 다음 제품 불러오는 중'을 보입니다.
- **previous:** 공유나 뒤로 가기로 목록 중간 장(`?page=2` 이상)에 들어왔을 때 목록 맨 위에 둡니다. 버튼을 눌러야만 앞 장을 불러옵니다.
- 검색 로봇이 장을 따라갈 수 있게 `href`로 장 링크를 함께 둘 수 있습니다.

## 쓰지 않는 경우

- 첫 로딩에는 Skeleton을 씁니다.
