# RangeSlider

손잡이 두 개로 단계 사이의 범위를 고르는 슬라이더입니다. 수분감·유분감처럼 '없음·낮음·보통·높음' 네 단계에만 멈춥니다. 라벨과 '상관없음' 칩이 있는 머리줄은 화면이 ToggleChip으로 조립합니다.

## 언제 쓰나

- 탐색 조건의 수분감·유분감처럼 범위를 고를 때 씁니다. 값은 (최소, 최대) 단계이고 늘 최소 ≤ 최대입니다.
- 두 손잡이를 같은 단계에 두면 그 단계 하나입니다. 양 끝(없음~높음)이면 조건이 없는 것과 같습니다.
- 선택 구간은 수분이면 droplet-moisture, 유분이면 droplet-oil 색(`tone`)입니다. 모든 단계에 눈금 점이 늘 보입니다.

## 쓰지 않는 경우

- 값 하나를 고를 때는 Slider를 씁니다.
- 단계 아래에 물방울 아이콘을 두지 않습니다. 이름과 손잡이 위치와 같은 정보를 반복하기 때문입니다.
