# ConfirmSheet

행동하기 전에 한 번 묻는 시트입니다. 안에서 BottomSheet를 쓰고 틀만 고정합니다. 제목(질문) → 이유 한 줄 → (선택) 내용 칸 → 취소 · 실행 순서이고, 내용 칸은 client가 채웁니다.

## 언제 쓰나

- 조건 충돌, 첨부 이미지 삭제, 선반에서 빼기, 로그아웃, 로그인 안내, 만 14세 확인처럼 행동 전에 한 번 확인받을 때 씁니다.
- 실행 버튼은 일반(`tone` 기본, Primary)이거나 위험(`destructive`: 빼기·삭제·로그아웃)입니다.
- 다른 시트나 사진 뷰어 위에도 뜰 수 있고, 닫으면 아래 시트로 돌아갑니다.

## 쓰지 않는 경우

- 머리에 ✕를 두지 않습니다. 하단 '취소'가 닫기 역할입니다.
- 카테고리 상품 성분 시트 안의 조건 충돌은 확인 시트를 겹치지 않고 바로 반영한 뒤 안내 줄(되돌리기)로 처리합니다(S33a · S35a).
- 결정이 필요 없는 결과 알림에는 Toast나 Notice를 씁니다.
