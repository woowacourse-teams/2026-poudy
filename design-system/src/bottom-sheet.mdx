# BottomSheet

화면 아래에서 올라오는 시트의 그릇입니다. `BottomSheet` 안에 `BottomSheetHeader` → `BottomSheetBody` → `BottomSheetFooter` 순서로 둡니다. 안의 행은 RadioGroup · CheckboxGroup · Disclosure를 그대로 쓰고, 시트 전용 행은 만들지 않습니다. 떠 있는 면은 `Portal`로 `#overlay-root`에 그립니다.

## 언제 쓰나

- **머리:** 필터·선택 시트는 제목 + ✕, 설명 시트와 시트 안 단계 화면은 ‹ 뒤로 + 제목입니다. 머리 높이는 숫자로 고정하지 않고 위 12 + 버튼 44 + 아래 16의 여백으로 정합니다.
- **본문:** 넘치면 본문만 스크롤합니다.
- **발:** 버튼은 틀이 그리고, 화면은 할 일(`primary`, `secondary`)만 넘깁니다. 보조 1 : 주 2, 간격 8이고 본문이 스크롤되어도 제자리에 남습니다. 버튼은 둘까지입니다.
- **높이:** 최대 '화면 − 상단 안전 영역 − 24'입니다. 가상 키보드가 열리면 그 위까지 줄입니다.

## 쓰지 않는 경우

- 행동하기 전에 한 번 묻는 시트는 ConfirmSheet를 씁니다.
- 발에 버튼을 셋 이상 두지 않습니다. 더 필요하면 명세에 하단 모양을 먼저 그립니다.
- 시트 안의 목록 행을 따로 만들지 않습니다. 선택 부품을 그대로 씁니다.
