# SearchField

검색 입력 칸입니다. 입력만 맡고, 결과 목록과 잇는 일은 Combobox가 합니다. 시트 안에서도 같은 부품이 폭을 채웁니다.

## 언제 쓰나

- 제품명, 성분명처럼 검색어를 받을 때 씁니다. 결과 목록이 함께 열리면 Combobox의 `ComboboxInput`을 씁니다(모양은 같습니다).
- 값이 있으면 오른쪽 끝에 지우기 버튼이 붙습니다. 보이는 원은 24이고 누르는 영역은 입력 칸 오른쪽 끝 44×44입니다.

## 쓰지 않는 경우

- 검색이 아닌 값을 받을 때는 TextField를 씁니다.
