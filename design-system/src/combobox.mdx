# Combobox

검색 입력과 결과 목록을 잇는 부품입니다. 상태와 키보드 처리만 맡고, 입력과 목록을 어디에 둘지와 목록 안의 행 모양은 화면이 정합니다.

## 구성

- `Combobox`: 값과 열림 상태, 결과 수 알림(`status`)을 맡습니다.
- `ComboboxInput`: 결과 목록과 이어진 검색 입력입니다. 모양은 SearchField와 같습니다.
- `ComboboxList`: 결과 목록(listbox)입니다. 닫히면 숨깁니다. 안에는 `ComboboxOption`과 `ComboboxGroup`만 넣습니다.
- `ComboboxGroup`: 목록 안에 제목 줄을 둘 때 씁니다. listbox 안에 제목을 그냥 넣으면 안 되기 때문입니다.
- `ComboboxOption`: 후보 하나입니다. 무엇을 골랐는지(상세로 이동, 성분 담기)는 후보마다 `onSelect`로 정합니다. 엔터가 고를 줄처럼 늘 눈에 띄게 둘 후보는 `emphasized`로 hover 면을 깔아 둡니다.

## 언제 쓰나

- 입력하는 동안 후보 목록(자동완성)을 보여 주는 검색에 씁니다.

## 쓰지 않는 경우

- 결과를 다른 화면이나 아래 목록에 보여 주는 검색은 SearchField만 씁니다.
