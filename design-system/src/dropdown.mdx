# Dropdown

버튼을 누르면 버튼 바로 아래에 목록이 열리고, 고르면 닫히는 부품입니다. 목록은 브라우저 popover로 열고, 자리는 CSS 앵커 위치가 버튼에 붙여 잡습니다.

<Unstyled>
  <SpecSources boards={["APP · 드롭다운", "MOTION M02", "A11Y D04"]} issues={["#726"]} source="src/dropdown.tsx" />
</Unstyled>

## 언제 쓰나

- 목록 결과 헤더의 정렬처럼 가벼운 자리에서 하나를 고를 때 씁니다. 목록의 이름(`aria-label`)은 쓰는 자리가 정합니다(정렬은 '정렬 기준').
- 옵션 높이는 40이고, 지금 기준은 ui-surface 면 + 600 + 오른쪽 체크 16입니다.

## 쓰지 않는 경우

- 폼 칸에서 고를 때는 시트를 여는 Select를 씁니다.
- 고를 것이 많거나 설명이 필요하면 시트 안의 RadioGroup을 씁니다.
