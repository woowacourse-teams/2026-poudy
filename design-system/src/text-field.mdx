# TextField

한 줄 입력입니다. 높이 48, 모서리 8, 좌우 여백 12의 회색 칸이고, 라벨과 안내·오류 문구를 함께 그립니다.

## 언제 쓰나

- 제품명, 닉네임처럼 한 줄로 끝나는 값을 받을 때 씁니다.
- 라벨은 14/700이고 필수가 기본입니다. 고르지 않아도 되는 칸에만 `optional`로 '선택'을 붙입니다.
- 안내 문구(`hint`)와 오류 문구는 같은 자리에 놓이고, 오류가 있으면 안내 대신 오류를 보여 줍니다.

## 쓰지 않는 경우

- 여러 줄을 받을 때는 TextArea를 씁니다.
- 정해진 값 가운데 고를 때는 Select(시트)나 RadioGroup을 씁니다.
- 검색어를 받을 때는 SearchField(결과 목록이 있으면 Combobox)를 씁니다.

## 검사 규칙(FieldRule)

무엇이 오류인지는 client의 도메인이 정하고, 오류를 언제 보여 줄지는 입력 부품이 정합니다. client는 칸마다 `FieldRule`을 만들어 `rule`로 넘깁니다.

- **기본:** 칸을 벗어날 때(blur) 처음 검사하고, 한 번 오류가 난 칸은 입력할 때마다 다시 검사합니다(FEEDBACK F06).
- **입력이 멈춘 뒤 검사:** `validateOn: "change"`와 `debounceMs`(기본 300ms)를 줍니다.
- 어느 쪽이든 손대지 않은 칸에는 오류를 띄우지 않고, 고치면 기다리지 않고 바로 지웁니다.
- 제출 버튼을 켤지 정할 때도 같은 `validate`를 부릅니다. 그래야 버튼 판단과 칸의 오류가 어긋나지 않습니다.
- 서버가 돌려준 오류는 `serverError`로 넘기면 시점 규칙 없이 바로 보여 줍니다.
