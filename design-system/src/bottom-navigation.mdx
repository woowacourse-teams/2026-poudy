# BottomNavigation

하단 탭 바입니다. 어떤 탭을 어떤 순서로 두고 어디로 보낼지는 앱이 `items`로 넘기고, 부품은 칸 배치, 지금 탭 모양, 키보드가 열릴 때 숨기기, 접근성만 맡습니다. 링크는 `linkAs`로 client의 `Link`를 넘깁니다.

## 언제 쓰나

- 다섯 칸(홈 · 카테고리 · 탐색 · 선반 · 마이)이고, 로그인 여부와 관계없이 이 하나만 씁니다.
- 높이 80(홈 인디케이터 여백 포함), 위쪽 1px ui-border, 흰 바탕입니다. 화면 골격(Screen)의 맨 아래에 둡니다.
- 지금 탭은 채운 아이콘(ui-brand-strong)과 굵은 라벨(ui-brand-text 600)입니다. 그래서 채움 그림이 있는 아이콘만 쓸 수 있습니다.
- 햅틱처럼 이동 말고 더 할 일이 있으면 `onSelect`로 받습니다.

## 쓰지 않는 경우

- 같은 화면 안의 전환에는 Tabs나 TabNav를 씁니다.
