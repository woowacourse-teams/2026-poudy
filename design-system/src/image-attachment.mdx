# ImageAttachment

사진 첨부입니다. 첨부 버튼(72×72)을 맨 앞에 두고, 사진(72×72)을 고른 순서로 잇습니다. 부품은 고르기, 미리 보기, 상태 표시, 지운 뒤의 포커스만 맡고, 업로드 요청과 취소·다시 시도는 쓰는 쪽이 넘깁니다.

## 언제 쓰나

- 문의하기(S40)와 선반 제품 등록 요청의 전성분 사진(S53h)에서 씁니다. 형식은 JPG · PNG · HEIC를 받습니다.
- 상태 줄(`status`)에 '2 / 5장 · 장당 5MB 이하' 같은 안내를, 실패하면 오류 문구(`error`)를 둡니다. 오류 문구는 실패한 사진에 잇습니다.
- 사진이 하나뿐인 자리에서는 `aside`로 첨부 버튼 옆에 안내를 둘 수 있습니다.

## 쓰지 않는 경우

- 사진 외의 파일 첨부에는 쓰지 않습니다.
