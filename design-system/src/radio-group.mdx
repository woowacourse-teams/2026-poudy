# RadioGroup

하나만 고르는 선택지 묶음입니다. `RadioGroup` 안에 `RadioGroupItem`을 늘어놓고, 모양은 `variant`로 고릅니다. 선택지마다 네이티브 radio를 시각적으로 숨기고 행이나 카드 전체를 누르는 영역으로 씁니다.

## 언제 쓰나

- **list:** 필터 시트의 소분류처럼 목록에서 하나를 고를 때 씁니다. 행 높이 48, 왼쪽 라디오 18, 이름 15/500입니다. 고른 행은 ui-layer 면에 이름 15/600입니다.
- **choice:** 성별, 나이대처럼 선택지가 적고 화면의 주된 입력일 때 씁니다. 높이 52(`md`)이고, 선택지가 많거나 폼 위쪽의 유형 선택이면 44(`sm`)입니다. 같은 줄의 버튼은 폭을 나눕니다.
- **card:** 피부 타입처럼 고를 근거가 되는 설명이 필요한 선택지에 씁니다. 그림 28, 이름 15/600, 설명 13이고 `columns`로 한 줄에 둘 개수를 정합니다. 3열이면 설명을 어절 단위로 줄바꿈합니다.
- **card-row:** 카드형 선택 줄입니다. 높이 72, 이름 15/400과 라디오 24이고, 그림과 설명을 더할 수 있습니다.

## 쓰지 않는 경우

- 여러 개를 고를 수 있으면 CheckboxGroup을 씁니다.
- 고르는 즉시 다른 화면으로 가는 선택은 링크(TabNav 등)를 씁니다.
- 선택 표시를 체크 아이콘이나 굵기만으로 전하지 않습니다. choice는 테두리와 글자색으로, card-row는 라디오를 함께 둡니다.
