# SwitchIndicator

행 단위 설정을 바로 켜고 끄는 스위치의 표시입니다. 40×24 트랙 안에 지름 20 흰 손잡이를 둡니다. 끄면 손잡이가 왼쪽, 켜면 오른쪽입니다. 누르면 바로 반영되고 저장 버튼은 없습니다.

표시만 그립니다. 누르는 쪽은 스위치를 감싼 행이라, 쓰는 화면이 행을 `role="switch"` + `aria-checked`로 만들고 `usePressable`을 붙입니다. 표시의 상태와 움직임은 그 행이 붙인 `data-hovered` · `data-pressed`를 보고 `switch-indicator` 유틸리티(`src/interaction.css`)가 그립니다.

## 언제 쓰나

- 켜면 바로 결과가 바뀌는 행 단위 설정에 씁니다. 예: 성분 탭의 '나만의 필터 적용' 행.
- 켠 트랙은 기본 `ui-action`(검정)입니다. `tone="brand"`는 켠 면을 분홍 계열로 칠하는 행(나만의 필터 토글 행 · 켬)에서만 씁니다.

## 쓰지 않는 경우

- 칩 줄 안에서 켜고 끄는 설정은 `FilterToggleChip`을 씁니다(같은 '나만의 필터'라도 S23 필터 칩 줄에서는 칩).
- 여러 값 중 고르는 선택은 RadioGroup · CheckboxGroup을 씁니다.
- 바꾼 뒤 확인·저장 버튼을 누르는 폼 안에서는 쓰지 않습니다. 스위치는 누르는 순간 반영된다고 읽히기 때문입니다.
