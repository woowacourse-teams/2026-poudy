# ToggleChip

눌러서 켜고 끄는 칩입니다. 여러 칩을 묶을 때는 `ToggleGroup`으로 감쌉니다. 하나만 고르는 것이 아니어서 RadioGroup과 다릅니다.

## 언제 쓰나

- **md(36):** 피하고 싶은 성분 같은 빠른 필터 줄에 씁니다. 칩은 글자 길이에 맞춰 늘어나고 여러 줄로 흘려 놓습니다.
- **sm(32):** 범위 슬라이더 머리줄의 '상관없음'처럼 헤더의 보조 칩에 씁니다.
- 라벨에는 '제외'를 붙이지 않습니다. 섹션 설명이 그 뜻을 맡습니다.

## 쓰지 않는 경우

- 시트를 여는 칩은 FilterChip을 씁니다.
- 하나만 고르는 선택지는 RadioGroup(choice)을 씁니다.
