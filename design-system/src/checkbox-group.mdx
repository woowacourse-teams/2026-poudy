# CheckboxGroup

여러 개 고르는 선택지 묶음입니다. 모양은 체크 목록 행 하나이고, 행마다 네이티브 checkbox를 시각적으로 숨기고 행 전체(높이 48)를 누르는 영역으로 씁니다.

## 언제 쓰나

- 탈퇴 이유, 나만의 필터에 넣을 성분처럼 여러 개를 고를 때 씁니다.
- 오른쪽 보조 글자(`description`, 예: '제품 2개에 있음')와 행 사이 나눔선(`divided`)을 고를 수 있습니다.
- 이름은 15/500이고 고르면 15/600입니다. 체크 표시는 네모 20, 고르면 ui-action 면에 흰 체크입니다.

## 쓰지 않는 경우

- 하나만 고르면 RadioGroup을 씁니다.
- 켜고 끄는 칩(빠른 필터)은 ToggleChip을 씁니다.
