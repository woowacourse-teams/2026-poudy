# Slider

값 하나를 고르는 슬라이더입니다. 기본은 0~3을 0.5 단위 7단계로 고르는 유수분 평가 슬라이더입니다. 오른쪽 위에 지금 값을 적고, 트랙 아래에 숫자와 양 끝 설명을 둡니다.

## 언제 쓰나

- 선반 평가에서 수분감·유분감을 매길 때 씁니다. 수분감은 droplet-moisture, 유분감은 droplet-oil 색입니다.
- 값이 `null`이면 고르기 전입니다. 손잡이와 채움을 그리지 않고 값 자리에 '선택 전'을 적습니다(S52i).

## 쓰지 않는 경우

- 범위를 고를 때는 RangeSlider를 씁니다.
