# TextArea

여러 줄 입력입니다. 회색 칸, 모서리 8, 안쪽 12, 최소 높이 140입니다. 입력이 늘면 5줄 분량까지 칸이 자라고, 그 뒤로는 칸 안에서 스크롤합니다.

## 언제 쓰나

- 문의 내용, 메모처럼 길게 적는 값을 받을 때 씁니다.
- `maxLength`를 주면 칸 안 오른쪽 아래에 글자 수를 둡니다. 오류 문구는 칸 아래에 둡니다.
- 검사 규칙은 TextField와 같은 `FieldRule`을 씁니다.

## 쓰지 않는 경우

- 한 줄로 끝나는 값에는 TextField를 씁니다.
