# Google 크롤링·출처 검증 (#942, #744)

## 운영 조치 (2026-10-23)

- 성분 사이트맵의 배포 전 캐시 한 항목을 갱신했다. 원본·공개 XML 2,332개와 lastmod 2026-10-22 일치를 확인했다.
- Nginx access log에 host·cache 필드를 추가했다. 설정 검사와 graceful reload 성공, 공개 요청 HTTP 200 확인.
- 사이트맵 재제출·색인 요청은 하지 않았다. 수동 요청을 하지 않을 관찰 URL 7개와 검사 대조군은 `deploy/config/google-crawl-observation.json`에 있다.
- 최초 집계는 `deploy/reports/google-crawl-baseline-20261023.json`이다. 짧은 관찰 구간의 0회 수집은 회복 실패 판정이 아니다.

## 성분 출처 대조

공식 최신 [표준화명칭목록](https://kcia.or.kr/cid/files/표준화명칭목록)을 10-23 내려받았다. 실제 파일 기준일은 **2026-09-30**이다.
공개 성분 API 목록과 비교했다. 한글명·영문명에서 NFC 정규화·공백·대소문자만 통일해 정확히 일치하고 공식 후보가 하나인 경우만 코드 비교에 포함했다.
PDF 줄바꿈·개명·빈 영문명·중복 후보 등으로 매칭하지 못한 행은 미확정으로 남겼다. 유사 이름으로 코드를 추정하지 않았다.

| 대상 | 전체 | 같은 코드 | 다른 코드 | 미확정 |
| --- | ---: | ---: | ---: | ---: |
| 제품에 쓰인 성분 | 2,332 | 270 | 1,938 | 124 |
| 전체 공개 성분 | 22,013 | 745 | 18,315 | 2,953 |

수치는 내부 ID와 공식 코드의 차이다. 잘못된 출처 문구의 전체 건수와 같다고 단정하지 않는다.
실제 API 표본에서는 비타민나무수(내부 6313), 헬리크리숨 스토에카스추출물(내부 10006), 글루코닉애씨드(내부 783)의 내부 ID가 출처의 공식 코드처럼 표기돼 있었다.

- [비타민나무수 공식 레코드](https://kcia.or.kr/cid/search/ingd_view.php?no=6366): 공식 6366. PDF 451쪽도 시각 확인했다.
- [헬리크리숨 스토에카스추출물 공식 레코드](https://kcia.or.kr/cid/search/ingd_view.php?no=10074): 공식 10074. PDF 717쪽 텍스트와 대조했다.
- 글루코닉애씨드: 공식 목록의 한글·영문명 일치 행은 784.

제품과 성분 연결에 쓰는 내부 ID는 바꾸지 않는다. 내부 번호를 공식 코드로 오인한 API·화면의 인용 표기를 제거하고, 공식 링크는 인용된 성분명 검색으로 만든다.
일반 분류 메모 두 종류는 참고문헌 건수에서 제외하고 성분 분류 참고자료와 완제품 효능 검증을 구분해 표시한다.
이 대조는 식별자·출처 표기 검수다. 개별 논문의 임상적 타당성이나 모든 효능 태그의 직접 근거까지 검증했다는 뜻은 아니다.

재현: 공개 `/api/ingredients?size=100&page=N` 목록을 JSON 배열로 저장하고 공식 PDF를 `pdftotext -layout`으로 추출한 뒤
`node client/scripts/audit-ingredient-codes.mjs <catalog.json> <official.txt>`를 실행한다.

## 배포·관찰

- #941의 사이트맵 캐시 초기화를 유지하고 세 사이트맵의 원본·공개 URL/수정일 비교를 배포 검증에 추가했다.
- DB V44는 주요 콘텐츠와 연관 데이터 변경을 추적한다. 피부 필터 전체 교체는 기존 집합 비교를 유지하며 조회수·회원 행동은 제외한다.
- 앱 배포 후 성분 상세 제품 링크·출처·표준 URL을 확인하고 새 관찰 구간을 시작한다. 로컬 변경을 운영 앱 반영 완료로 기록하지 않는다.
- 운영 로그 관찰: `sudo python3 deploy/scripts/report-google-crawls.py --config deploy/config/google-crawl-observation.json`.
  공식 IP 범위와 대조하며 Googlebot·검사 도구를 구분한다. Googlebot만으로 수동 요청 유발 여부는 확정할 수 없다.
- 현재 Work 설정에서 로컬 브라우저 사용이 비활성화돼 시각 검증은 미완료다. HTML·타입·자동 테스트 검증과 구분한다.
