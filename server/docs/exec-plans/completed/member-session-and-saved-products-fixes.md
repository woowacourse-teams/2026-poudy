# 회원 세션과 저장함 리뷰 수정

## 승인된 설계

- CORS에서 PUT을 허용하고 저장 API의 사전 요청을 검증한다.
- security에 활성 회원 확인 포트를 두고 MemberService가 구현한다. 회원 API 요청마다
  PK로 활성 상태를 확인하며, 탈퇴하거나 삭제된 회원의 세션은 종료하고 401로 거절한다.
- 저장·해제마다 변경 번호를 올린다. 조회 중 변경이 생기면 응답을 버리고 진행 중인
  변경 요청이 끝난 뒤 다시 조회한다.
- 저장 훅은 요청 결과 Promise 또는 로그인 이동 시 null을 반환한다. 저장함은 먼저
  표시를 바꾸고 실패하면 서버 상태로 복원한다. 목록·상세의 분석 이벤트 기준은 요청 시작이다.

## 검증

- PUT 사전 요청, 다른 기기의 탈퇴 세션, 프로필·저장함·로그아웃의 공통 차단
- 오래된 조회 응답, 진행 중 저장·해제, 실패한 삭제·되돌리기
- 서버 공식 verify, 클라이언트 테스트·타입 검사·린트
