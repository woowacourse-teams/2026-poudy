- [x] 공통 질의 준비와 단일 검색 본체로 이름·메타데이터의 토큰 재검사를 제거한다.
- [x] 조건 충족 여부를 명시하고, 이후 기존 순위·페이지 계약에 연결한다.

최초 규칙은 선크림/썬크림뿐이다. 원문·기존 검색 열과 인덱스를 보존하고 상품 검색용
표준값을 저장한다. 완성 표현을 포함하지 않은 입력은 기존 값으로 비교한다.
정렬·페이지 및 외부 DB 함수·HTTP 계약을 유지하며 성분·공유 매칭은 확장하지 않는다.
규칙 변경 시 검색 문서를 갱신해 저장된 표준값과 인덱스를 함께 반영한다.

변경과 검증은 [성능 기록](../../performance/product-equivalent-spelling-797.md)에 둔다.
이전 구현·복제 페이지·중간 실험 자료는 최종 diff에 포함하지 않는다.
V35 검증은 일반·혼합 검색 12,800개 표본을 추가했다. 고정 #703 성능 기준 48개 모두 충족했으며,
측정 범위는 로컬 합성 데이터·동시 호출 1·jit=off이다. 운영 부하나 HTTP 왕복은 검증하지 않았다.
