# 핵심 도메인 행동 소유권 교정 계획

## 상태

- 상태: 완료
- 시작일: 2026-09-03
- 완료일: 2026-09-03
- 대상 영역: 제품·성분 검색, 상세 조회 조립, 필터 협력 경계

## 배경

접근자의 `public`을 제거하는 것만으로는 책임이 이동하지 않는다. 핵심 객체의 상태를 검색용
래퍼가 꺼내 판단하던 구조를 제거하고, 제품과 성분이 자신의 이름 검색 행동과 파생 검색 상태를
직접 소유하도록 교정한다.

## 결정

- `SearchableProduct`와 `SearchableIngredient`의 검색 상태와 행동을 각각 `Product`와
  `Ingredient`로 이동한다.
- `Products`와 `IngredientCatalog`는 검색 래퍼가 아니라 핵심 객체를 직접 인덱싱한다.
- 도메인 판단을 표현하는 메서드는 의미 있는 공개 행동으로 제공한다.
- DTO 변환에 필요한 접근자는 유지한다. 사용하지 않는 상태 접근자는 가시성만 낮춰 숨기지 않고,
  실제 호출이 필요 없으면 제거한다.
- 제품 상세 조회 결과 조립은 전송용 결과 객체의 팩토리가 맡고 `Product`가 다른 카탈로그를
  직접 조율하지 않는다.
- 제품 공유 이름 해석은 별도 `share` 도메인의 규칙이므로 제품 이름을 읽는 기존 경계를
  유지한다. 공유 전용 규칙을 `Product` 행동으로 위장하지 않는다.
- HTTP 응답, 검색 순위, 필터·정렬·집계 결과와 저장 데이터 계약은 유지한다.

- [x] 임의로 낮춘 접근자의 공개 의미를 재검토하고 교정한다.
- [x] 행동 기반 검색·필터·상세 테스트를 통과시킨다.

## 완료 조건

- 검색 래퍼가 핵심 객체의 getter로 검색 상태를 조립하지 않는다.
- 핵심 객체가 자신의 이름 검색 판단을 직접 수행한다.
- DTO·저장소·일급 컬렉션 및 별도 공유 해석 경계 외의 호출자가 상태를 꺼내 도메인 판단을
  작성하지 않는다.
- 기존 API와 검색 결과가 유지되고 전체 서버 검증이 통과한다.

## 검증 결과

- 제품·성분 도메인과 제품 Service·Repository 관련 회귀 테스트 통과
- `sh ./scripts/verify.sh` 통과
- 전체 Gradle 테스트, Checkstyle, Spotless 통과
- OpenAPI와 공통 Zod 산출물 변경 없음
