# 제품 전체 성분의 주의 태그

이슈 #649. #648과 같은 `feat/product-ingredient-cautions` 브랜치에서 제품 상세의 개별 성분에 주의 기준을 추가한다.

## 결정과 범위

- `ingredient_group.tag_name`을 추가하고 제외 성분군 6개의 짧은 문구를 채운다. 다른 성분군은 NULL을 허용한다.
- 문구는 향료, 건조 알코올, 자극성 방부제, 설페이트, 실리콘, 합성 색소로 한다.
- 제품 성분마다 필수 `cautions: [{code, label}]` 배열을 반환한다. 해당 기준이 없으면 빈 배열이다.
- 기존 성분군 소속으로 판정하며 제외 성분군 6개만 대상으로 한다. 기준 순서는 제품 상세의 주의 성분군 순서를 따른다.
- 피부 작용 태그는 기존처럼 첫 번째 하나만 표시하고, 주의 태그는 해당하는 것을 모두 빨간 배지로 표시한다.
- 기존 성분 순서와 접힌 목록의 앞 5개 표시를 유지한다.
- 바텀시트의 포함 성분을 개별 성분의 `cautions`로 찾아 제품 상세의 `/api/exclude-codes` 추가 호출을 제거한다. 다른 화면의 호출과 서버 API는 유지한다.

## 커밋 전략

1. `feat`: 마이그레이션, 도메인·응답, 생성 계약, 클라이언트 적용과 회귀 테스트를 하나의 기능으로 반영한다.
2. `docs`: 완료된 계획과 검증 결과를 기록한다.

## 검증

- 제외 성분군의 태그 문구를 DB에서 읽고 누락된 문구를 거절한다.
- 한 성분의 여러 주의 기준, 빈 배열, 구성품별 판정과 일반 성분군 제외를 검증한다.
- 필수 `cautions`, `code`, `label`의 OpenAPI 계약을 확인한다.
- 모든 주의 태그와 피부 작용 첫 번째 태그의 동시 표시, 접기·펼치기, 바텀시트의 포함 성분을 확인한다.
- 서버 `verify.sh`와 클라이언트 포맷·린트·타입·전체 테스트·프로덕션 빌드를 통과시킨다.

## 결과

- V10 마이그레이션으로 기존 주의 성분군 6개의 `tag_name`을 채운다. 실제 마이그레이션을 기존 행에 적용하는 테스트로 문구와 일반 성분군의 NULL을 확인했다.
- 제품 상세의 `cautions`는 기존 성분군 소속에서 계산하며 DB의 태그 문구를 사용한다. 여러 기준 소속, 빈 배열, 일반 성분군 제외, 구성품별 판정과 필수 API 계약을 검증했다.
- 전성분 행은 주의 태그를 모두 표시하고 기존 피부 작용 첫 번째 태그를 함께 표시한다. 성분 순서와 앞 5개 접기, 바텀시트의 포함 성분을 검증했다.
- `sh ./scripts/verify.sh` 통과: API 생성물 드리프트 없음, 서버 테스트 1,071개와 전체 빌드 통과. 새 컬럼을 스키마 검증의 기대 목록에도 반영했다.
- `pnpm run check` 통과: 린트·포맷·타입 검사, 126개 파일의 테스트 1,131개와 프로덕션 빌드 통과.
