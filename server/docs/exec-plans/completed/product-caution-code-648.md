# 제품 상세 주의 성분군 코드 추가

이슈 #648. 제품 상세의 주의 성분 항목을 표시명 대신 코드로 성분군 상세에 연결한다.

## 범위와 결정

- `ExcludeGroupResponse`에 필수 문자열 `code`를 추가하고 기존 `name`, `contains`와 순서를 유지한다.
- OpenAPI와 공통 Zod·타입 선언은 `generateApiArtifacts`로 생성한다.
- 클라이언트는 제품 상세 응답의 코드를 링크·바텀시트·분석 이벤트에 사용한다.
- `/api/exclude-codes` 조회는 유지하고, 제품에 포함된 성분을 찾을 때 코드로 연결한다.
- 성분별 `cautions`와 제품 상세의 추가 조회 제거는 #649에서 다룬다.

## 커밋 전략

1. `feat`: 서버 응답과 생성 계약, 클라이언트의 코드 기반 연결, 목 데이터와 회귀 테스트를 하나의 기능으로 커밋한다. 필수 필드가 추가된 공통 타입과 소비 코드를 함께 반영한다.
2. `docs`: 완료된 작업 계획과 검증 기록.

## 검증

- 제품 상세가 포함 여부와 관계없이 모든 주의 성분군 코드를 반환하는지 검증한다.
- OpenAPI에서 `code`가 필수 문자열인지 검증한다.
- 이름이 달라도 코드로 포함 성분을 찾으며, 제외 성분군 조회가 비어도 상세 응답의 코드로 시트를 열 수 있는지 검증한다.
- 서버 `sh ./scripts/verify.sh`와 클라이언트 포맷·린트·타입·테스트·빌드를 실행한다.

## 검증 결과

- `sh ./scripts/verify.sh` 통과: 생성물 일치, 서버 테스트 1,065개, Spotless·Checkstyle와 전체 빌드.
- 클라이언트 포맷·린트·Next.js 타입 생성·타입 검사 통과.
- 클라이언트 전체 테스트 126개 파일, 1,129개 테스트 통과.
- `pnpm run build` 통과. 최초 샌드박스 실행은 Turbopack의 로컬 포트 권한 오류로 실패했다. 오류가 저장된 빌드 캐시를 임시 폴더로 옮기고 권한 제약 없이 재실행해 성공했다.
- 서버가 새 필드를 반환한 뒤 클라이언트를 반영한다. 이번 변경은 DB 마이그레이션을 요구하지 않는다.
