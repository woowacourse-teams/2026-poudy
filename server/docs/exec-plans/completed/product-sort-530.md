# 제품 목록 정렬 개편 (#530)

## 범위와 계약

- 기준: `origin/feat/backend-postgres-migration`의 `c1a6eed8`.
- 서버 `GET /api/products`의 정렬 허용값을 `DEFAULT`, `PRICE_DESC`, `PRICE_ASC`, `UNIT_PRICE_DESC`, `UNIT_PRICE_ASC`로 바꾸고, 미지정은 `DEFAULT`로 처리한다. 클라이언트 변경은 범위 밖이다.
- 검색어가 있으면 기존 PostgreSQL 검색 순위, 없으면 한국 시간 기준 어제까지 완료된 30일의 조회수 내림차순을 기본순으로 쓴다. 미집계 조회수는 0이다.
- 가격과 단가는 목록에 표시하는 대표 옵션을 사용한다. 단가는 `ml`과 `g`의 가격÷용량 수치를 단위 변환 없이 함께 비교한다. `ea`와 용량 0은 양방향 정렬에서 마지막이다. 동점은 제품 ID 오름차순이다.

## 구현

1. 제품 목록 SQL에서 검색 함수의 순위를 후보에 보존하고 필터 후 기본순으로 정렬한다.
2. 조회수 기간과 대표 옵션의 단가를 목록 SQL에서 계산한 뒤 페이지를 자른다. 조회수 집계는 검색어 없는 기본순에서만 수행한다.
3. 요청 enum, 관련 테스트, OpenAPI와 서버 소유 공통 생성물을 갱신한다.

## 검증

- 검색 관련도·조회수 기간·단가 예외·동점·필터 후 페이지·미지정과 잘못된 값의 API 동작을 테스트한다.
- `server/scripts/verify.sh`를 실행해 생성물과 전체 빌드를 확인한다.

## 완료

- 한국어 로케일 PostgreSQL 18.6에서 정렬 통합 테스트를 통과했다.
- `server/scripts/verify.sh`가 생성물 드리프트 없이 전체 빌드와 794개 테스트를 통과했다.
