# 핵심 도메인 행동 캡슐화 보완 계획

## 상태

- 상태: 완료
- 시작일: 2026-09-03
- 완료일: 2026-09-03
- 대상 영역: 제품·성분 핵심 도메인과 Service·검색·상세 조회 호출 경계

## 배경

도메인 record를 일반 클래스로 바꾸었지만 record 스타일 접근자를 그대로 공개하고 호출자가
꺼낸 상태로 판단한다면 책임 이동은 완료되지 않는다. 핵심 도메인은 자신의 상태를 감추고,
상태에 관한 판단과 계산을 의미 있는 행동으로 제공해야 한다.

## 결정

- 제품 필터는 성분 컬렉션을 꺼내지 않고 `Product`에 필터 적용을 요청한다.
- 제품 상세 조립은 Service가 제품 내부 상태를 꺼내 조합하지 않고 도메인 조립 경계에 맡긴다.
- DTO 변환, 저장소 연결, 일급 컬렉션 인덱싱처럼 데이터를 전달해야 하는 경계를 제외하면
  공개 접근자를 사용하지 않는다.
- 제품 공유 이름 해석처럼 다른 도메인이 소유해야 하는 규칙을 억지로 `Product`에 넣지 않는다.
  이 경우에는 읽기 경계를 유지하되 제품 자체의 판단인 것처럼 위장한 행동을 만들지 않는다.
- 테스트는 가능한 한 내부 컬렉션이나 값 노출보다 공개 행동과 결과를 검증한다.

## 완료 조건

- Service와 필터가 `Product`의 카테고리·성분 상태를 꺼내 판단하지 않는다.
- DTO·저장소·컬렉션 인덱싱 외의 새 판단 로직이 공개 getter에 의존하지 않는다.
- 검색·필터·상세 응답 계약과 기존 결과가 유지된다.
- 전체 서버 검증이 통과한다.
