# 가입 프로필 설정 재개

## 목표와 결정

- 새 가입자가 닉네임·사진 페이지의 [다음]을 누르기 전 종료·로그아웃하면 재로그인 시 해당 페이지로 돌아온다.
- 기존 회원에게는 재설정을 요구하지 않는다. 마이그레이션으로 기존 행은 완료 처리하고 새 회원의 기본값은 미완료로 둔다.
- 완료 여부는 세션·브라우저 저장소가 아닌 회원 테이블에 보관한다.
- 기존 프로필 PATCH에서 닉네임·사진과 함께 완료를 기록한다. 검증 또는 이미지 연결이 실패하면 완료도 롤백한다.
- 회원 조회 응답에 완료 여부를 추가하고 웹 OAuth·앱 로그인 모두 공통 callback의 회원 조회 결과로 분기한다.
- 완료 처리 전에는 로그인 복귀 경로를 소비하지 않는다. 프로필 → 피부 정보 이후 기존 복귀 흐름을 유지한다.

## 범위와 검증

1. 회원 상태·V52 마이그레이션·조회/프로필 DTO와 저장소 연결
2. 가입 [다음]의 완료 요청 및 로그인 callback의 미완료 분기
3. 신규/기존 회원, 완료 후 재로그인, 실패 롤백, 완료값 유지와 마이그레이션 테스트
4. 서버 전체 verify, 클라이언트 타입·테스트와 프로덕션 빌드 검증

## 결과

- 신규 회원 미완료·기존 회원 완료 마이그레이션과 저장/롤백·재로그인 경로 구현 완료.
- 완료 상태 유지 판단은 User가 소유하고, 서비스가 회원 행 잠금 안에서 계산한 상태를 저장한다.
- 서버 verify: 1,800개 테스트, 아키텍처·스타일·생성물·빌드 모두 통과.
- 클라이언트: 린트·포맷·타입·1,683개 테스트와 Webpack 프로덕션 빌드 통과.
- 독립 코드 리뷰에서 실행 가능한 결함 없음. 실제 외부 OAuth·네이티브 앱 강제 종료는 직접 실행하지 않았다.
