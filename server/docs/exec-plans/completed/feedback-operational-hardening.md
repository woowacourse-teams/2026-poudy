# 피드백 등록 운영 안정성 보강 계획

## 상태

- 상태: 완료
- 시작일: 2026-08-24
- 소유 도메인: `feedback`

## 목표

인증 없이 공개된 피드백 등록 API가 반복 요청으로 S3와 Discord를 무제한 호출하지 않게 하고,
S3 장애가 nginx의 30초 응답 제한을 넘어 서버 요청 스레드를 점유하지 않게 한다.

## 결정

- 유효한 피드백은 클라이언트 주소별 고정 시간 창으로 제한한다.
- 운영 nginx가 덮어쓰는 `X-Real-IP`를 우선하고, 직접 실행 환경에서는 원격 주소를 사용한다.
- 기본 정책은 제품 등록 요청과 같은 시간당 5회이며 초과 응답은 `Retry-After`가 있는 429다.
- S3 전체 호출은 15초, 개별 시도는 5초로 제한해 nginx 제한보다 먼저 실패한다.
- S3 저장 성공 후 Discord 실패를 성공으로 유지하는 기존 부분 실패 정책은 바꾸지 않는다.

## 완료 조건

- 같은 클라이언트의 시간 창 초과 요청은 외부 호출 전에 429로 거절된다.
- 시간 창이 지나거나 다른 클라이언트이면 정상 접수된다.
- Feedback S3 클라이언트의 전체·시도별 timeout이 각각 15초·5초다.
- 생성물이 최신이고 전체 서버 빌드와 테스트가 통과한다.
