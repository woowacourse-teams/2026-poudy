# 향수·클렌징 제품 유수분 제거

이슈 #814. 제품 상세·목록·선반과 API에서 향수·클렌징 제품의 유수분을 제공하지 않는다.

## 결정

- 대분류 이름 `향수`, `클렌징`을 기준으로 모든 하위 카테고리에 적용한다. 전체 제품 로더와 목록 카드 로더가 같은 ProductSensory 정책을 사용한다.
- 해당 제품의 유수분 응답은 0과 구별되는 null이다. 저장된 추론값은 읽는 경계에서 제외한다. 유수분 필터를 적용한 목록·개수에는 해당 제품을 포함하지 않는다.
- 선반 제품에 sensorySupported를 제공해 평가 입력 노출 여부를 결정한다. 기존 선반 평가의 유수분도 읽을 때 null로 가리고 선호도는 유지한다.
- 선반 등록·수정에서 null이 아닌 유수분 값(0 포함)을 받으면 저장 전에 400 INVALID_REQUEST_BODY로 거절한다. null 또는 생략은 평가 없음으로 취급한다.
- 서버 OpenAPI를 재생성해 공통 타입을 갱신한 뒤 클라이언트에 반영한다.

- [x] 클라이언트 표시·평가 입력 변경

## 검증

- 전용 임시 PostgreSQL에서 `sh ./scripts/verify.sh` 통과: API 생성물 일치, 아키텍처 검사, 포맷·정적 검사, 전체 테스트 1,290개 및 빌드.
- 클라이언트 전체 테스트 1,465개 통과. 제품 카드·상세·상단 축약 영역과 선반 평가 입력 회귀 테스트 포함.
- 클라이언트 타입 검사 통과. 린트의 기존 디자인 토큰 경고는 이번 작업의 변경 대상이 아니다.

- 선반 평가 반환 책임을 `ShelfProduct.ratingFor(product)`로 옮겨 `ShelfItem`의 내부 평가 객체 탐색을 제거했다. 기존 API·예외 계약을 유지하고, 새 책임의 도메인 테스트와 기능·계층 패키지 순환 검사를 통과했다.

- PR 생성 전 최신 `dev`를 반영하면서 화면 배치·아이콘과 선반 분석 갱신 동작을 유지해 충돌을 해결하고 검증을 다시 실행했다.
