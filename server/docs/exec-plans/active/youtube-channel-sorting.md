# 유튜버 홈 순서와 목록 정렬 분리

- 관리자: 드래그·방향키·이동 버튼으로 홈 표시 순서를 편집하고 명시적으로 저장한다.
- 기존 단건 Order API를 재사용한다. 부분 저장 실패 시 초안을 유지하고 전체 순서를 재전송한다.
- 유튜버 목록: 관리자 Order 대신 조회수 합계(기본), 구독자, 최신 업데이트, 추천 제품 수 내림차순으로 정렬한다. 동률은 채널 이름·ID로 결정한다.
- 조회수 합계: 등록된 업로드 영상 전체를 한 번씩 합산한다. 1년 이전·서비스 미노출 영상도 포함하며 미래 영상은 제외한다. YouTube 채널 전체를 새로 수집하지 않는다.
- 추천 제품 수: 공개 API가 반환한 제품 중 recommendedVideoCount > 0인 서로 다른 제품 수.
- 최신 업데이트: 기존 channel.updatedAt(채널 메타데이터 갱신 시각).
- 목록 제품 이미지 축소, 제품 상세로 직접 이동. 홈 카드의 제품 이동 동작은 유지한다.
- 검증: 드래그 저장·실패 재시도, 4가지 정렬·동률·링크, 서버 조회수 중복 방지, 생성 계약, 백엔드 verify와 프런트 정적 검사 및 브라우저 확인.

## 검증 현황 (2026-11-06)

- 프런트 관련 10개 테스트, 타입 검사, 수정 파일 ESLint·Prettier 통과.
- OpenAPI 재생성 드리프트 없음. 백엔드 전체 1,964개 중 1,963개 통과; 기존 UserRepositoryTest.findsOnlyWithdrawnUser만 DB 시계가 호스트보다 약 64분 늦어 실패. 테스트 완화 없이 환경 시각 동기화 후 verify 재실행 필요.
- 로컬 API totalViewCount 반환 및 브라우저 4가지 정렬, 홈 섹션 위치 확인.
- 목록 제품 링크는 /products/{id}로 이동. 로컬 미러 DB는 제품 카테고리·성분 정의를 생략한 시범 데이터이므로 기존 제품 상세 API는 500을 반환함. 상세 렌더링은 완전한 카탈로그 환경에서 재검증 필요. 임시 카테고리 진단 변경은 원복함.
- 관리자 실제 브라우저 로그인, 드래그→저장→새로고침 유지 확인. 검증 후 기존 순서 복원 저장 완료. 자동 테스트에서도 드래그·방향키·부분 실패 재시도 통과.
- 로컬 재시작 시 CLIENT_DOMAIN 누락으로 발생한 로그인 CORS 오류 복구. 기존 관리자 아이디·해시는 유지. 이후 재시작에서는 인증값뿐 아니라 CLIENT_DOMAIN 등 기존 실행 환경 전체를 보존해야 한다.
