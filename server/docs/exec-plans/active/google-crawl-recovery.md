# Google 크롤링 복구 (#942, #744)

2026-10-23 진단에서 성분 사이트맵의 배포 전 캐시 잔존을 원본·공개 XML 비교로 확인했다.
선택적 운영 캐시 갱신은 완료했다. 기존 수집 정체의 단일 원인으로 단정하지 않는다.

## 작업

- 사이트맵 원본·공개 URL/수정일 비교를 배포 검증에 포함한다. 캐시 초기화는 최신 dev의 #941을 유지한다.
- 표준 제품 링크와 분석 유입 문맥을 분리하고 성분 상세에 대표 제품 링크를 제공한다.
  포함 제품은 성분 상세 API의 `productSize`로 요청한다. 생략 시 미리보기는 조회하지 않으며, 프론트의 제품 목록 추가 요청을 제거한다.
- 주요 콘텐츠의 자기 행 및 연관 데이터 INSERT/UPDATE/DELETE가 수정일에 반영되도록 DB에서 보장한다.
  조회수·회원 행동·단순 재적재의 동일 값 변경은 제외한다. 과거 삭제 시각은 복원하지 않는다.
- 호스트·캐시 상태를 로그에 포함하고 IP 검증된 Googlebot과 검사 도구를 구분한다.
- 근거 자료를 검수하고 수동 요청을 하지 않을 비교 URL의 초기 상태를 남긴다.

## 검증

운영 DB 대신 임시 로컬 PostgreSQL에서 마이그레이션과 서버 검증 전체를 실행한다.
클라이언트 타입·회귀 테스트 및 배포 스크립트 테스트를 실행한다.
DB 마이그레이션의 쓰기 경로 영향과 연관 콘텐츠 전파를 명시해 검토 가능하게 남긴다.
자연 크롤링·색인 전환은 후속 관찰 결과로 판정하며 즉시 회복을 보장하지 않는다.

리뷰 보완: 성분 사이트맵 수정일은 연결 제품의 수정일과 함께 집계해 미리보기 변경을 반영한다. 추가 쓰기 전파 대신 기존 제품 수정일을 집계하므로 양방향 트리거 순환을 만들지 않는다.
