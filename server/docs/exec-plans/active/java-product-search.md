# 상품 검색의 Java 분석기 전환

- 상태: 구현·검증 완료 (2026-10-19). 실제 배포와 운영 자료 생성은 별도 작업이다.

## 목표와 승인 범위

상품 검색의 한글 조합·자모 표현·영문 읽기·원문 위치를 Java가 소유한다. `product/search` 안에서 업무 개념을 나누고 전용 협력 객체를 책임 소유자 아래에 둔다. 검색과 관계형 필터·순위·페이지·개수는 PostgreSQL에서 계산한다. API와 인기 검색어의 입력 집계 규칙, 성분 검색과 공유 매칭은 유지한다.

## 구현 순서

- [x] 검색어와 이름에 공통으로 쓰는 순수 Java 분석기와 UTF-16 위치 매핑
- [x] 표현별 검색 자료 테이블과 분석된 조건만 받는 SQL
- [x] 검색·목록·count·결과 유무 확인의 공통 서비스와 Repository
- [x] 독립 실행 분석 명령과 초기/추가 적재의 같은 트랜잭션 연결
- [x] 사례·전체 한글·API·기존 경로 비교·적재 롤백·패키지 의존 검증
- [x] ADR, 실행 절차 갱신과 `scripts/verify.sh`

## 전환 원칙

기존 SQL 함수와 뷰는 이전 서버·성분·공유 매칭·교정 경로가 사용하므로 보존한다. 새 자료는 Java 분석 버전을 함께 저장하고, 스키마 확장 → 기존 자료 분석 → 새 서버 전환 순서로 반영한다. Flyway에서 외부 Java 프로세스를 실행하지 않는다. 상품 자료와 분석 자료는 같은 트랜잭션에서 커밋한다. 일반 검색의 자모 표현과 모음을 합치는 오타 교정 표현을 섞지 않는다.

PR #800의 미병합 SQL 자모 분석 구현을 제거하고 최신 dev를 반영했다. V20은 배너 변경이 사용하므로 새 구조는 V21로 추가한다.
별도 `poudy-private` 작업 트리에는 기존 변경이 있어 적재 연결에 필요한 부분만 추가하고 기존 변경은 보존한다.


## 확인한 결과

- 최신 dev 통합 후 `scripts/verify.sh` 통과. OpenAPI·TypeScript 생성물 변경 없이 전체 테스트 1,390건, 포맷·정적 검사·빌드가 통과했다.
- 실제 독립 실행 JAR, 초기 적재 SQL·실행 패키지·추가 적재·분석 실패 및 후속 실패 롤백 9건 통과.
- 기존 Python 추가 적재·패키징 23건과 초기 적재 생성기 5건 통과.
- 독립 검토는 상품 472개·표현 2,156개에서 129개 질의의 4,378행을 기존 함수와 비교했다. ID·등급·일치 비율·순서·이름 필드·원문·UTF-16 범위가 모두 일치했다.

### DB 비용 확인

[측정 원자료](java-product-search/benchmark.tsv)는 로컬 PostgreSQL 18.6, JIT off, 전용 DB에서 실행한 비교다.
상품 스냅샷은 `poudy-private`의 커밋된 `output.zip`(501개, SHA256
`17f2960be006b067db8fc0733bc7c3f3fed95402e284a76491532dc9a8fe2692`)이다.
브랜드 23개·분류 15개와 이름을 사용했고, 유수분·가격은 검색 판정에 관여하지 않는 고정값을 넣었다.
20배 자료는 상품명에 ` 벤치N`을 붙여 상품명 고유 제약을 유지한 10,020개 합성 자료다.

기존 `search_products(query,0,20,3)`와 새 `search_product_hits`의 동일한 정렬·페이지·전체 개수·JSON 결과를 비교했다.
새 조건은 실제 Java 분석기와 Repository 인코더로 만들었다. 대표 질의 6개는 두 자료 크기 모두 total·items 전체가 같았다.
각 질의·구현에서 6회 워밍업 후 EXPLAIN ANALYZE의 Execution Time 30개로 p50·p95를 계산했다.

| 질의 | 501개 p95 기존 → 새 구현(ms) | 10,020개 p95 기존 → 새 구현(ms) |
|---|---:|---:|
| 크림 | 3.651 → 1.939 | 41.915 → 30.474 |
| 수분 | 4.934 → 1.800 | 35.885 → 9.912 |
| 토너 | 3.522 → 1.446 | 35.538 → 11.357 |
| ㅌㄴ | 4.344 → 2.227 | 50.727 → 31.171 |
| PDRN | 3.273 → 1.438 | 20.583 → 8.139 |
| 라운드랩 1025 독도 토너 대용량 기획 | 6.083 → 2.665 | 87.413 → 28.875 |

이는 결과와 DB 비용을 확인한 로컬 측정이다. Java 분석·JSON 인코딩·네트워크 시간, 실제 API 필터·동시 부하·운영 JIT 설정을 포함한 지연이나 SLO 검증을 뜻하지 않는다.
