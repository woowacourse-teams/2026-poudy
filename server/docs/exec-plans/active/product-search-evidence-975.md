# 제품 검색의 일치 근거와 정책 분리 (#975)

- 이슈: https://github.com/woowacourse-teams/2026-poudy/issues/975
- 기준: origin/dev 323a9ffa
- 상태: 진행 중. 공통 근거 도입·중복 판정 축소만 구현·검증했고 전체 단계 분리는 미완료다.
- 인계 기준일: 2026-10-27.

## 목표와 경계

저장용 분석과 검색어 분석, 인덱스 후보 수집, 필드·브랜드 결합 일치, 결과 포함·순위,
표시를 구분한다. 검색과 연관검색어가 같은 일치 근거를 사용하도록 SQL의 중복 판정을 줄인다.
정규화의 Java 이전, MV 확장, 검색엔진 도입, 기존 정책 변경은 포함하지 않는다.
속성·마크는 일반 뷰에서 현재 연결을 조회하고 기존 공개 DB 함수와 HTTP 계약을 유지한다.

## 진행 순서

1. 현재 검색·연관검색어를 비교 기준으로 고정하고 테스트 DB를 준비한다.
2. 신규 V46에서 분석 결과·필드 일치·브랜드 결합 근거를 분리한다.
3. 포함·순위·표시가 공통 근거를 사용하도록 본체와 연관검색어 조회를 전환한다.
4. 전후 결과·순위·강조·개수·페이지와 현재 데이터 반영을 비교한다.
5. 대표 조회의 실행 시간과 실행 계획을 확인하고 전체 verify.sh를 실행한다.
6. 현재 구조와 정책별 수정 지점을 문서화하고 검증 결과를 기록한다.

## 보존할 계약

- 전체 입력·필수 토큰·브랜드 결합의 인정 조건과 표준 표기/부분 토큰 구분.
- 최대 등급 2의 모든 조건 충족과 내부 등급 3의 부분 일치 호환성.
- 기존 순위, 조회수 기간, 페이지와 전체 개수, 필터 선택지의 자기 그룹 해제.
- 결과가 없을 때의 교정, 실제 연결된 메타데이터만 교정 후보에 포함.
- 원문 UTF-16 강조, 표시 필드 우선순위, 연관검색어 접두어와 길이 제한.
- 속성값·마크 표시명과 연결 변경의 REFRESH 없는 반영.

## 검증

기존 PostgresSearchTest, ProductSearchStructureTest, ProductSearchMigrationTest,
ProductMetadataSearchTest, ProductSuggestionAndSearchTest와 연관검색어 테스트를 사용한다.
신규 근거의 중복 토큰·필드 경계·결합 품질과 V43 대비 동등성을 검증한다.
실행 계획과 시간 비교는 동일한 테스트 자료에서 수행하고 운영 성능으로 일반화하지 않는다.

## 결과

- V46에서 공통 근거를 도입하고 검색·연관검색어의 중복 판정을 줄였다. 포함·순위·표시의 완전한 분리는 남아 있다.
  V43의 250줄 검색 본문은 역할별 함수로 나뉘었고 가장 긴 본문은 79줄이다.
- 연관검색어 Repository의 약 110줄 SQL을 공통 근거를 사용하는 DB 함수 호출 한 줄로 바꿨다.
  MV·인덱스와 속성값·마크의 실시간 연결 조회는 유지했다.
- 51개 입력의 이름 전용/메타데이터 포함 결과·원문 범위·페이지·연관검색어와
  80개 추가 페이지·등급 조건을 전후 비교했다(284개 스냅샷).
  필드 근거·결합 조각·호출 계획 재사용 뒤 표기 규칙 변경도 검증했다.
- 규칙 함수 교체 후 기존 연결에서 표기 인식이 이전 규칙을 사용하는 문제를 발견했다.
  `search_product_has_spelling`의 SQL 인라이닝을 막고 회귀 테스트를 추가했다.
- `verify.sh` 통과: 테스트 1,781개, 실패·오류·생략 0개. OpenAPI/TypeScript 생성물 드리프트 없음.
  Node shim에 버전이 없어 처음 실행은 실패했고, 설치된 버전을 `MISE_NODE_VERSION=22.23.3`으로
  지정해 전체 검증을 완료했다. 검증 명령이나 테스트 조건은 약화하지 않았다.
- 개발 DB와 분리한 PostgreSQL 18.6에서 2,700개 성능 표본과 실행 계획 8개를 보관했다.
  대표 입력은 빨라졌지만, 1,000개 일치 목록 검색은 p50 10.727→14.727ms로 느려졌다.
  운영 카탈로그·동시 요청 검증과 이 비용의 수용 여부는 배포 전에 판단해야 한다.

현재 호출과 수정 지점은 [제품 검색 구조](../../product/product-search.md),
수치·측정 범위·재현 절차는 [성능 비교](../../performance/product-search-975.md)에 있다.
