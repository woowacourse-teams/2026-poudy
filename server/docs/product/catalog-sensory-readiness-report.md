# 카탈로그 감각 준비도 결과

## 문서 지위

2026-08-17 외부 카탈로그 snapshot에 v0 estimator와 감사 도구를 적용한 **과거 결과**다.
현재 저장소의 운영·테스트 JSON에 그대로 적용되는 최신 보고서가 아니며, 관능 정확도의
증거도 아니다. 원본 제품·성분 식별 데이터와 1,048줄 JSON 파생물은 저장소에 남기지 않고,
재현에 필요한 입력 hash와 의사결정에 쓰인 집계만 보존한다.

snapshot 결과처럼 재생성됐다고 주장하지 않는다.

## 역할 태그 준비도

| 기준 | 고유 성분 | 출현 수 |
| --- | ---: | ---: |
| 인식 가능한 formulation role | 734/1,009 (72.75%) | 4,889/7,623 (64.13%) |
| v0 감각 선별 role | 278/1,009 (27.55%) | 2,480/7,623 (32.53%) |

`ABSORBENT` 참조는 0건이고 `HUMECTANT`는 고유 성분 3개뿐이었다. 기존 CosIng role을
감각 프로필로 그대로 사용할 수 없으며, phase·휘발성·잔류감·레올로지와 농도 조건이 있는
별도 프로필이 필요하다.

빈출 성분 중 1,2-헥산다이올(179제품)과 카프릴릴글라이콜(59제품)은 함량 근거 없이 축
신호를 추가하면 대규모 결과 이동을 만들 수 있어 v0 보정을 보류했다. 정제수, 나이아신아마이드,
판테놀, 아데노신, 카보머와 실리카도 빈출하지만 감각 역할이나 v0 프로필만으로 자동 보정하지
않는다.

## 이 결과가 남긴 결정

- v0는 재현 가능한 baseline이지 관능 모델이 아니다.
- 다음 단계는 성분 ID 몇 개를 더 가산하는 것이 아니라 원천·농도·제형·phase·dry-down을
  연결하는 것이다.
- 공식 사용법과 제형 표현이 없는 제품은 검수 대기열로 보내야 한다.
- 새 snapshot은 입력 manifest와 generator 버전을 갖는 결정적 보고서로 다시 만들어야 한다.
